# 拿到 Offer 后要做什么

申请入境许可（签证）、申请宿舍、办理学生证、选课……刚被录取的你，或许还手忙脚乱，害怕自己错过了什么重要的事情。不必担心——这条属于 HKUer 的时间线，RIC 帮你安排梳理！

{% hint style="info" %}
提示：**点击链接**，可查看对应指南页面！
{% endhint %}

{% stepper %}
{% step %}
### 6 月末 – 7 月

* 在系统中**接受 Offer**，并缴纳**留位费（Admission Deposit）**；
  * 高考生（含港澳台联考）：[2026 年香港大学内地本科生入学计划 回复录取通知书指引](https://admissions.hku.hk/sites/default/files/2024-06/Procedures.pdf)
  * 国际生：[How to Respond to Your HKU Offer of Admission](https://0ea19992-1e51-4ec5-bcea-01a7628a8588.filesusr.com/ugd/83c572_1ffe3bdc5cbd484485f999e21c504163.pdf)
* 申请[**签证（入境许可）**](visa/)；
  * 由于申请程序用时可能较长，建议**尽早**开始申请。
* **（非本地生）**[**选择、申请宿舍**](residence/)**。**
  * 由于宿位有限，建议**尽早**完成申请。
* 如收到题为 Registration for New Full-time Undergraduate Students 的邮件，则需根据其中要求，**依次**完成：
  * （获得账号信息后）访问 HKU Portal，并完成 [**Master Registration**](master-registration.md)**（主注册 / 正式注册）**；
{% endstep %}

{% step %}
### 8 月上旬 – 中旬

* 收到 Welcome Email；根据其中要求，**依次**完成：
  * （获得账号信息后）[**Master Registration**](master-registration.md)**（主注册 / 正式注册）**；
  * （完成 Master Registration 后）[**上传学生证所需文件**](student-card.md)；
  * **（本地生）**[**选择、申请宿舍**](residence/)**。**
* [**了解课程要求，初步安排课表**](course-selection/)；
* 收到签证 / 入境许可后：
  * 办理[**港澳通行证和/或逗留（D）签注**](visa/exit-entry-permit.md)；
  * 预约申领[**香港居民身份证（HKID）**](hkid-application.md)。
{% endstep %}

{% step %}
### 8 月下旬

* **正式选课**；
* 参加[**迎新营（Orientation Camp，O Camp）等迎新活动**](freshmen-activities/)。
{% endstep %}

{% step %}
### 8 月末 – 9 月初

* 领取**学生证**；
* 办理八达通、电话卡、银行卡等。
{% endstep %}

{% step %}
### 9 月上旬

* （Add/Drop Period 期间）**选课、加课、退课**；
* 办理**学生八达通。**
{% endstep %}

{% step %}
### 9 月中下旬

* 缴纳**学费、住宿费**。
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
注：本文根据往年综合时间整理而成。本年度具体时间点请以学校的**官方邮件等**为准。
{% endhint %}
