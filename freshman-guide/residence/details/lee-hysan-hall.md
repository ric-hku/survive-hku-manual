# 利希慎堂入住指南

### A 基本信息(位置&性别&室友) <a href="#a-ji-ben-xin-xi-wei-zhi-xing-bie-shi-you" id="a-ji-ben-xin-xi-wei-zhi-xing-bie-shi-you"></a>

### 1. 位置 <a href="#id-1-wei-zhi" id="id-1-wei-zhi"></a>

沙宣道6号B座，位于沙宣道学生舍堂村中间那一栋楼（民间叫法称为四村。但在23年黄竹坑的新舍堂被港大官方命名为“赛马会第四学生舍堂村”后，沙宣道舍堂村可能会失去作为四村的民间叫法）。

### 2. 性别构成 <a href="#id-2-xing-bie-gou-cheng" id="id-2-xing-bie-gou-cheng"></a>

共12个常规(学生居住的)楼层，其中8层男女同层分别在两个wing居住，2层男层，2层女层。同性别的两个人可以一起给Office发邮件要求一起居住。

### 3. 舍友背景 <a href="#id-3-she-you-bei-jing" id="id-3-she-you-bei-jing"></a>

从2023年起，港大校委会决定为了促进交流融合，在新学年将内地新生安排与本地生或者国际学生做室友。宿舍办公室将为入住两人或三人房的新入住宿生配对室友，务求本地生要和非本地生，包括海外和内地生住同一间房。留宿第二年起可以自行选择室友或者根据各Hall内部安排确定新室友（但一般情况下只能满足大部分同学的诉求，不能保证百分之百满足）。新生最初默认分到双人间，单人间需要向Hall Office写邮件提出申请（如果因为身体原因需要单人间，则必须提供医生开具的证明。任何时候均可提出申请，需于waiting list等候）。学期中如果有空床位也可以申请调换，Hall Office会酌情考虑。

注: 虽然学校分配宿舍时秉承尽量让内地新生与本地生或国际学生做室友的原则, 但入住时房间分配可能会被本层的local调换, 从而让内地生与内地生做室友, 本地生与本地生做室友。(如果对房间分配不满意也可自行与同楼层的其他学生协商进行私下调换)

### B 居住概况(房间&床&家具) <a href="#b-ju-zhu-gai-kuang-fang-jian-chuang-jia-ju" id="b-ju-zhu-gai-kuang-fang-jian-chuang-jia-ju"></a>

### 1.房间类型 <a href="#id-1-fang-jian-lei-xing" id="id-1-fang-jian-lei-xing"></a>

单人间双人间都有，大陆生一般会被分到双人间。

\*Hysan是有纱窗的!这是重要福利, 怕蚊虫的小盆友们看过来!

(虽然有时还是需要电蚊香)

### 2. 房间尺寸 <a href="#id-2-fang-jian-chi-cun" id="id-2-fang-jian-chi-cun"></a>

双人间尺寸和Starr类似，约为12平方米，单人间约是双人间的一半。

### 3. 卫生间&浴室 <a href="#id-3-wei-sheng-jian-yu-shi" id="id-3-wei-sheng-jian-yu-shi"></a>

每层两翼各两个浴室，24小时热水。Hysan的浴室算是设施比较新的。

### 4. 床 <a href="#id-4-chuang" id="id-4-chuang"></a>

床大约为 $$1.85 * 0.92$$ 米。Hall提供床垫，但是床单、枕头、被子等其他床上用品全都要自己准备。懒得带过来也可以来港后去宜家或者日本城购买。另外2022年初Hall内换过床垫后新床垫较硬，同学可能需要适应一段时间，或者自己准备一个垫子在床垫上。如果同学们和室友作息不同步也可以考虑买支架一体式床帘。

### 5. 空调 <a href="#id-5-kong-tiao" id="id-5-kong-tiao"></a>

冷气需自行交费, 使用八达通给冷气系统充值(最低1港币)。每千瓦时(度)电约为1.5港币且每年按实际电价递增, 每晚大约10-20港币。冬天温度最低8度左右, 如果有怕冷的同学可以考虑购买加热器。

### C 衣物相关(洗衣机&衣柜) <a href="#c-yi-wu-xiang-guan-xi-yi-ji-yi-gui" id="c-yi-wu-xiang-guan-xi-yi-ji-yi-gui"></a>

### 1. 洗衣&烘干 <a href="#id-1-xi-yi-hong-gan" id="id-1-xi-yi-hong-gan"></a>

顶层（16层）有四台洗衣机、四台烘干机，有露天平台晾衣服，但是没有顶蓬挡雨而且风大容易吹走，所有机器均为八达通付款。洗衣4港币一桶，40分钟左右；烘干2港币10分钟，通常需要1小时左右干透。

G层出Hall门左拐有Laundry Room，提供四台洗衣机、四台烘干机，所有机器均为八达通付款，收费同上。

### 2.衣物储存 <a href="#id-2-yi-wu-chu-cun" id="id-2-yi-wu-chu-cun"></a>

衣柜尺寸:大概 $$0.8 * 0.6 * ($$ 楼层高度 -0.5 $$)$$ (单位:m) 的衣柜，上层衣柜+下层3个衣橱。床下另有三个衣橱 $$(0.5 * 0.4 * 0.15)$$ 。可以自备衣架，不过一般之前的Hall友会留下一些。

### D 饮食概况(餐厅\&Pantry&售货机) <a href="#d-yin-shi-gai-kuang-can-ting-pantry-shou-huo-ji" id="d-yin-shi-gai-kuang-can-ting-pantry-shou-huo-ji"></a>

### 1. 附近餐厅 <a href="#id-1-fu-jin-can-ting" id="id-1-fu-jin-can-ting"></a>

舍堂附近有玛丽医院K座1层的员工餐厅（一般是7折，折后和学校食堂价格差不多，有时甚至更便宜）、正院地下的太平洋咖啡等餐厅，价格适中，可凭借学生证享受折扣优惠；旁边医学院新楼有一家Grove，工作日8点到晚上6点营业，卖一些简单的吐司和意面。

李嘉诚医学院内有Subway赛百味三明治(但一般下午17:45停止落单)。校内的商店与餐厅会因假期减少营业时间。

新开了两家餐厅Pizza Express Kiosk（周一-周五09:00-18:00，周末及节假日关闭）、Sandwich Club Kiosk（周一-周五08:00-16:00，周末及节假日关闭）。可在学校官网上查到https://[www.cedars.hku.hk/campuslife/catering/catering-outlets/#SR](http://www.cedars.hku.hk/campuslife/catering/catering-outlets/#SR)

楼下7-11便利店(营业时间:7:00-22:00)

沿沙宣道下山可以到数码港，大约需要步行三十分钟，有很多餐厅(麦当劳等)。平时可以叫外卖，建议和同学一起叫，因为有些餐厅要求的送外卖起步价较高。另外keeta一般有优惠，运费十港币左右。

### 2. Pantry <a href="#id-2-pantry" id="id-2-pantry"></a>

Hall内每层有一个公用厨房，相应厨具和餐具每层自己决定，之前楼友们合买的厨具一般会保留下来，标准配置是电磁炉+微波炉+锅碗瓢盆+各种调味品。但多数楼层需要缴纳层费来使用这些层友共同购买的用品。有的层有烤箱，但通常很脏。每层1～2个冰箱，正常家用冰箱大小。每层有冷热直饮水，取水十分方便。Hall附近没有超市，食材一般去坚尼地城各种超市、西宝城惠康、数码港百佳、华富村商场等地采购，一般做巴士或者23路小巴去HKU附近或者坚城买。

请同学们注意不要在宿舍房间里做饭，因为烟雾报警器很灵敏，另外顺便提一下对于Hall内的火警门不要随意推动，很可能会引发火警与叫来消防车。

### 3. 自动售货机 <a href="#id-3-zi-dong-shou-huo-ji" id="id-3-zi-dong-shou-huo-ji"></a>

二楼公共区域有5台贩卖机，常见的零食和饮料比较齐全，24小时供应，全部使用八达通。

### E 学习环境(书桌&自习室) <a href="#e-xue-xi-huan-jing-shu-zhuo-zi-xi-shi" id="e-xue-xi-huan-jing-shu-zhuo-zi-xi-shi"></a>

### 1. 书桌与自习室 <a href="#id-1-shu-zhuo-yu-zi-xi-shi" id="id-1-shu-zhuo-yu-zi-xi-shi"></a>

书桌大小没有测量，不过够摆两台电脑(其中一个带鼠标)+水壶+一摞放倒的书(反正就是很大)。有两层书架，capacity绝对超越港大学生读书的平均水平。书桌上面有桌灯、插座。3楼有琴房，复习期间改为自习室，平时也可以自习。只要没人弹琴就随便进，不过电源插座时好时坏。

3楼common area也有桌子椅子和电源，可以学习。每层pantry有桌椅沙发和电源，local不闹的时候依然可以学习。二楼203也是自习室，就在3楼琴房的正下方，一般Hall SA会在203开会，没有开会的时候可以进去自习。

### 重要福利: <a href="#zhong-yao-fu-li" id="zhong-yao-fu-li"></a>

1. 沙宣道有医学图书馆，学霸们周末不用去学校哦\~而且final季主校区人满为患时医图往往还有许多无需预定的空位、更显优越感！医图的24小时自习室也十分舒适，可以让人学习到欲罢不能。只是医图一般温度较低，尤其是G层与24小时自习室，夏天大约21度左右，同学们来自习记得带好外套。
2. 四村对面的沙宣道6号教学楼1F开设自习空间和Grove三明治，方便四村同学自习和用餐。
3. 医图旁边蒙民伟楼2F也有learning common可以学习，环境良好。

4.窗户有纱窗。

### 2. 打印&复印 <a href="#id-2-da-yin-fu-yin" id="id-2-da-yin-fu-yin"></a>

Hall内G层电梯口有打印机，和学校的papercut系统一致，可以从网页或者客户端上传文件打印，同学们再也不用额外学稳定性堪忧的插件了。

### F 活动 & 相关设施(活动室 & 活动队) <a href="#f-huo-dong-xiang-guan-she-shi-huo-dong-shi-huo-dong-dui" id="f-huo-dong-xiang-guan-she-shi-huo-dong-shi-huo-dong-dui"></a>

### 1. 活动室 <a href="#id-1-huo-dong-shi" id="id-1-huo-dong-shi"></a>

function room大大的有，你可以问问他们乐队的人都到哪里去练band。一间独立钢琴房，一间band房，还有三楼巨大的common area可以用作ball room。楼顶有BBQ area，烤架Hall提供，但似乎需要预定，也基本上没有见人用过。band room隔音效果比较好，可以录音/录视频，但是band room对外不隔音，住418/417的同学可能能免费听演唱会。

### 2. 体育运动 <a href="#id-2-ti-yu-yun-dong" id="id-2-ti-yu-yun-dong"></a>

3楼305室为小型健身室，提供一套哑铃、两台跑步机、一台立式健身车、一台多功能倒蹬机、一台可调式哑铃椅；开放时间一般为09:00-02:00。

最近的运动场所是港大的Stanley Ho Sports Centre。坐落在贝沙湾沙湾径，从四村沿小道走下去大约15分钟（但是由于有一段非常陡峭的楼梯，上来大约需要20分钟且较为艰难）。运动设施齐全，你能想到的几乎全有，也有游泳池（具体设施可参考cse.hku.hk，或参考@港大RIC锐克的公众号推文如何优雅地使用CSE体育设施）。

沙宣道以及下去的数码港道都是跑步好场所。傍晚海景美得难以言状。从四村步行到百周年校区约30分钟、主校区约40分钟。

### 3. Hall内其他活动 <a href="#id-3hall-nei-qi-ta-huo-dong" id="id-3hall-nei-qi-ta-huo-dong"></a>

Hysan最出名的就是舞狮队，这是港大唯一一支舞狮team，不过好像很chur的样子，内地生慎入。Hysan三大球(足球、篮球、排球)的男子Hall team比赛成绩都很不错，喜欢运动的同学们欢迎加入。每年会有一个Hysan festival，不过几乎没有内地生参加。每学期末有劲过活动，跟其他Hall没什么太大区别。

每年10-11月有打水仗的传统，会弄得走廊房间到处都是，到时候建议提前把房门堵好。请认真做好防水措施，这不是演习！不过女生层似乎没有打水仗的活动。

内地生主要强制参加的活动是High Table Dinner, 利希慎属于High Table比较多的舍堂, 可能一学期会举行三次, 但质量参差不齐, 在2023年春举办过饱受吐槽的Hall楼下空地摆盆菜的High Table, 2023年秋曾将湾景作为HTD地点, 希望同学们有心理准备。

### G Readmission考核标准 <a href="#greadmission-kao-he-biao-zhun" id="greadmission-kao-he-biao-zhun"></a>

不论是本地生或非本地生，都需要在每年四月通过 HKU Portal 提交续住申請。从 2023-24 年起，申請人需要具备 CGPA>=2.0 的学业成绩。

Lee Hysan 的readmission政策为50% Need score, 50% Merit score。Need score 用于评估同学们的住宿需求，主要由同学家离学校远近决定，non-local的distance score均为100（满分）。Merit score 中50%为contribution, 50%为GPA。

### 注： <a href="#zhu" id="zhu"></a>

Lee Hysan的内地生参加hall内活动一般较少，最好没有翘High Table记录，不然很有可能被踢。其他可能对non-local的要求宿舍都会在邮件中说明，例如邀请全员参加Hall tutor的留任投票。友情提示:跟楼主搞好关系，被readmit的概率会大一些。

Appeal可以给warden或者tutor发长信，内容最好能写来年contribution的打算，proposal越详细越好，(虽然不是真的要去做，但是得表明诚意)。以及不要把过去contribution没有做好归咎于自己主观原因，可以多找一些客观原因。

对于readmission分数在录取边缘徘徊的同学，Hall会采取interview的方式。

具体readmission标准可参考: [http://www.ase.hku.hk/halls/2024/59-424.pdf](http://www.ase.hku.hk/halls/2024/59-424.pdf)

### 小巴： <a href="#xiao-ba" id="xiao-ba"></a>

55:(去四村)新院有落、坐到终点。

8/28: (去四村)转弯有落、沙宣道有落／(去学校)地铁站有落。

注：“有落”是粤语“有人要下车”的意思，读作“油咯”，香港乘小巴快到站需要和司机说明自己要下车了。

以上非校巴方式车资约5-8港币，全程时长约15分钟。

### 6. 往来其他地点 <a href="#id-6-wang-lai-qi-ta-di-dian" id="id-6-wang-lai-qi-ta-di-dian"></a>

西环石塘咀: 以上方式往来香港大学百周年校园(香港大学地铁站C1口), 经由地铁站／西宝城楼梯链接至石塘咀。或乘小巴54往来玛丽医院附近及皇后大道西／卑路乍街。

### 西环坚尼地城： <a href="#xi-huan-jian-ni-di-cheng" id="xi-huan-jian-ni-di-cheng"></a>

从玛丽医院乘小巴23/23M，终点站为坚尼地城港铁站，很方便，但经常会遇到满座上不去车的情况；小巴54/54M往返玛丽医院附近及坚尼地城地铁站附近；也可乘坐大巴到达蒲飞路，再走一段下坡到达坚尼地城

数码港:步行,或乘坐30X/970(终点站/玛丽医院)。注意970X并不经数码港。

铜锣湾: 沙宣道、玛丽医院站均有前往铜锣湾的小巴，铜锣湾往玛丽医院的小巴大概在谢斐道信和广场位置等车。

上环、中环:4X/30X/37X(早晨特别班次)/90B经山道天桥快速到达上环、中环等地，适合实习工作的同学选乘。30X玛丽医院直达香港大学百周年校园站不停沿途。

中环码头:91和7终点站为中环码头, 如果要从中环码头坐船的话坐这两路巴士很方便来回港铁沿线地点可参考以上方式先抵达香港大学地铁站。

### J 整体感受(资深住户的感想) <a href="#j-zheng-ti-gan-shou-zi-shen-zhu-hu-de-gan-xiang" id="j-zheng-ti-gan-shou-zi-shen-zhu-hu-de-gan-xiang"></a>

1. Hysan属于local和non local隔阂比较大的Hall，这里的隔阂不是贬义，而是说hysan一直以来有local和non local分别自己抱团的传统。local的活动从来不强制大陆生参加，而他们活动的性质也非常local，大陆生不好参加。（大多数楼层的local都喜欢玩到比较晚，但是pantry隔音较好，如果local只在pantry内部聚会的话一般不会影响睡觉）。不过Hysan每年会录不少大陆生，所以大陆生抱团也是一个传统。新生一般会较快地形成一个自己的community，可以在Hall里交到不错的朋友。
2. 沙宣道处于偏远的富人区，离campus较远，但并不代表交通不便，只是需要更长的交通时间，交通费用可能较高。玛丽医院是巴士大站，坐巴士去很多地方都很方便（比如坐A10去机场感觉比坐地铁机场快线还要便宜方便）。纵观沙宣道周围，它其实有很多其他Hall没法比拟的地理优势——三幢Hall的同学独享医学图书馆，学生打折的玛丽医院食堂（菜品比SU和太古都多很多），十分方便的运动场和gym，坐车直达数码港、海洋公园、赤柱、旺角和尖沙咀，在富人区尤其是碧瑶湾寻到高薪家教的机会，晚上下课后远离校园的轻松氛围，当然必不可少的是让你看到眼麻的超级无敌大海景。
3. 简单从此宿舍本身与周边环境评价一下利希慎吧。Hall本身来讲，硬件设施上和其他Hall大同小异。在Hysan入住会较少有Hall的归属感和氛围感，当然如果愿意主动reach out可能local同学也还算礼貌，但更多时候能感受到local和non-local间的隔阂。local也会比较吵，但一般在夜晚12点以后开始，早睡的同学可以较早去洗漱入睡，就会较少被打扰且洗澡也不用排队。对于Hall周边，同学们可能有些忌惮四村临近坟场，但其实看习惯了也没有很吓人、平常也不会经过，位置远离繁华的市区能享受到与众不同亲近自然的感觉，从四村爬山、去海边都较为方便，海景也是真的很令人满意，周边配套设施也算方便。交通上校巴晚上六点半就是末班、若要乘坐港铁都需要先到港大、巴士费不算便宜；饮食方面，晚上很可能只能选择22:00关门的7-11或者点外卖；医学图书馆对专心学业的同学而言确实很棒。总得来说确实不必作为首选，但被分到利希慎也无需悲伤。
