# 太古堂入住指南

[Swire Hall 官方网站](https://www.swire.hku.hk/)

### A基本信息 <a href="#a-ji-ben-xin-xi" id="a-ji-ben-xin-xi"></a>

位置 & 性别 & 室友

### 1. 位置 <a href="#id-1-wei-zhi" id="id-1-wei-zhi"></a>

太古堂位于校内，靠近香港大学东闸。地处梁錶锯楼（商学院，俗称 KKL/KKLB）和徐展堂楼之间，到纽鲁诗楼（建筑学院，俗称 KB）步行需 5 分钟。如果不熟悉路线可以一出地铁站就打开导航，亲测好用。

### 2. 性别构成 <a href="#id-2-xing-bie-gou-cheng" id="id-2-xing-bie-gou-cheng"></a>

男女混住（但男女生不会住在同一层）。男生层分别为 1、2、3、4、8 层；女生层为 5、7、9、10 层。

### 3. 室友背景 <a href="#id-3-shi-you-bei-jing" id="id-3-shi-you-bei-jing"></a>

从 2023 年起，港大校委会决定为了促进交流融合，在新学年将内地新生安排与本地生或者国际学生做室友。宿舍办公室将为入住两人间的新入住宿生配对室友，务求本地生要和非本地生，包括海外和内地生住同一间房。留宿第二年起可申请自行选择室友。

### B 居住概况 <a href="#b-ju-zhu-gai-kuang" id="b-ju-zhu-gai-kuang"></a>

房间 & 床 & 家具

### 1.房间类型 <a href="#id-1-fang-jian-lei-xing" id="id-1-fang-jian-lei-xing"></a>

通常住双人间，尺寸在 13 平方米左右。

### 2.房间尺寸 <a href="#id-2-fang-jian-chi-cun" id="id-2-fang-jian-chi-cun"></a>

4.5m\*2.95m。转角房比普通房间大很多，运气好的话能被分到。

### 3.卫生间&浴室 <a href="#id-3-wei-sheng-jian-yu-shi" id="id-3-wei-sheng-jian-yu-shi"></a>

每层有卫生间及浴室，浴室以隔间分开，提供淋浴。每层有四个洗脸池，四间淋浴间，淋浴间空间较小。

### 4.床 <a href="#id-4-chuang" id="id-4-chuang"></a>

床的尺寸是 210cm\*90cm，提供床垫，自己需要准备床单，枕头，枕头套，被子等各种你想用的床上用品，不方便从家里带的话可以在宜家购买。人性化的设计是每人都有一个床头柜（有的房间没有）可以放一些触手可得的物品。并且在床头有插座。可摇头电扇也在床上方的墙上。房间有空调。床底有三个储物柜，可以放一些杂物。

5.家具

房间内每人各有一张床，一个书桌以及一个衣柜（详情在下文中介绍）。部分房间还有小杂物柜。

### 6. 空调 <a href="#id-6-kong-tiao" id="id-6-kong-tiao"></a>

空调可以在每一层的缴费站用八达通缴费，空调费用较贵，同学们要省电哦。

### C 衣物相关 <a href="#c-yi-wu-xiang-guan" id="c-yi-wu-xiang-guan"></a>

### 洗衣机&衣柜 <a href="#xi-yi-ji-yi-gui" id="xi-yi-ji-yi-gui"></a>

### 1. 洗衣 & 烘干 <a href="#id-1-xi-yi-hong-gan" id="id-1-xi-yi-hong-gan"></a>

Hall 内有洗衣机，烘干机和晾衣服的地方（位于 11 楼），洗衣机和烘干机都需要使用八达通。没有八达通的同学需要尽快办理。烘干机使用八达通或硬币（Dryer1 和 2 为大的烘干机，虽然需要 4min/HKD ——其他烘干机 5min/HKD，但是烘干效率极高）。洗衣房外有一个小阳台，也可以选择将衣服挂在阳台上，虽空间有限，却能享受太阳的味道。太古堂夕晒比较强烈，下午晾晒衣物干的快点。

### 2.衣物储存 <a href="#id-2-yi-wu-chu-cun" id="id-2-yi-wu-chu-cun"></a>

衣柜尺寸有 $$68cm × 212cm × 59cm$$ （不要问我为什么这么精确，我是一个有尺子的学长），除此之外衣柜上面可以放置皮箱，衣柜旁边可以有抽屉和格子可以放置乱七八糟的东西。床底还有三个大抽屉。衣柜里面没有衣架。书桌上方有三个可以放置杂物的隔板，可根据需要调整高度，十分人性化。

### D 饮食概况 <a href="#d-yin-shi-gai-kuang" id="d-yin-shi-gai-kuang"></a>

### 餐厅\&Pantry &售货机 <a href="#can-ting-pantry-shou-huo-ji" id="can-ting-pantry-shou-huo-ji"></a>

### 1. 楼内餐厅 <a href="#id-1-lou-nei-can-ting" id="id-1-lou-nei-can-ting"></a>

太古楼共有 2 家餐厅，分别是楼下方树泉文娱中心内 1 层的印度餐厅和 2 层的太古餐厅。对 Swirian 来说不仅有多种口味可供选择，更能享受极大的地理位置优越、交通便捷的区位优势，解锁“复习周一周不出太古”的成就决不是浪得虚名的。

### - 太古餐厅 <a href="#tai-gu-can-ting" id="tai-gu-can-ting"></a>

首先就是与美心，su 共同被戏称为坑 u 三大校内食堂的太古餐厅。菜单一般分为早餐，午餐，下午茶，晚餐四个时段更换。除了日常必备的烧味饭，意面，咖喱，午市双/三餧等常见套餐，太古餐厅最为出名的就是米线套餐。许多重口味达人会在点单时帅气地要求大辣，劲辣一解对辣椒的思念之情。除此以外，太古餐厅也会不定期推出川式 / 沪式口味套餐 / 夏日特饮 / 冬日特饮以供选择，日常探索菜单并解锁新菜品也可谓是相当有趣。价格方面，烧味和两餧在 20-40 左右，咖喱和米线 30 +，与校外的大快活&大家乐相比也算相当公道了。八达通/微信支付/支付宝/现金支付（现金仅限人工 counter）都是 ok 的，并且这里也是校内可以给八达通充值（仅限现金）的地方之一哦。

### ● 印度餐厅 <a href="#yin-du-can-ting" id="yin-du-can-ting"></a>

其次是在 1 层的印度餐厅。鸡肉/牛肉炒饭以及卷饼非常美味。小伙伴们可以在这里尝试各类咖喱和 Kebab 的新口味喔！（35\~45HKD）

### 2. 楼外觅食 <a href="#id-2-lou-wai-mi-shi" id="id-2-lou-wai-mi-shi"></a>

作为一个出色的 Swirian，几年下来的必备技能之一就是东下徐展堂外出觅食。出了东闸，近有 phd 比萨，日料，马来亚 / 港式 / 印度 / 墨西哥餐厅。甚至是深夜（23:00 以前）麦记的狂欢，稍远一点就是水街各色美食大会。诸如周记的流沙西多士，oppa chicken 的韩式炸鸡，京香饺的家乡味道等等等等，那一刻的心中简直回响着中华小当家经典的 bgm，感受到了食物的光芒！如果再沿着般咸道往东边就可以走到西营盘地铁站，（据粗略估计太古到港大站和西营盘站距离相当）路途上会经过通往高街的扶手电梯，于此途径便可以解锁各路网红餐厅诸如阿元来了，以及不算网红的一碗小面、请坐，米其林推荐英记面馆，川菜川之源以及新疆莱巴依餐厅。另外，高街上的各式西餐厅也是约会套路的不二之选。更有蔬果摊供应新鲜便宜的水果蔬菜。

### 3. Pantry（自己动手，丰衣足食） <a href="#id-3pantry-zi-ji-dong-shou-feng-yi-zu-shi" id="id-3pantry-zi-ji-dong-shou-feng-yi-zu-shi"></a>

2F，6F 和 9F 有自己的大 pantry，但各层其实也有自己的小型 pantry （大约容纳一两人的空间）。麻雀虽小五脏具全。比如 7 楼的小 pantry 有电磁炉，各色小锅和厨具，各式各样见过没见过的调料，蒸煮还是很方便的。但如果要打个边炉，炸个春卷儿，就需要去 6F 大 pantry 里一展身手了。需要的食材之类可以在东闸麦记旁边的 711 便利店（食物种类不多）/麦当劳再往东沿着般咸道走一小段先后会有百家和惠康超市（东西多），B2 口以及 C 口西宝城惠康（最远但是东西最全）等买到，或者前往校内庄月明文娱中心的百佳购买。

### 4. 自动贩卖机 <a href="#id-4-zi-dong-fan-mai-ji" id="id-4-zi-dong-fan-mai-ji"></a>

Hall 内 6F，太古楼 GF 以及 2F 分别设有自动贩卖机。同时 KKL GF，庄月明 GF（有华御结饭团，夜宵的小确幸）也有自动贩卖机

### E 学习环境 <a href="#e-xue-xi-huan-jing" id="e-xue-xi-huan-jing"></a>

书桌 & 自习室

### 1. 书桌 <a href="#id-1-shu-zhuo" id="id-1-shu-zhuo"></a>

书桌有 $$130 cm × 60 cm$$ , 有三层书架和台灯和三个抽屉。

### 2.自习室 <a href="#id-2-zi-xi-shi" id="id-2-zi-xi-shi"></a>

Hall 内没有学习室。不过 6 楼的 common area 以及每个楼层的 pantry 如果没人用都可以用来自习。

### 3. 打印 & 复印 <a href="#id-3-da-yin-fu-yin" id="id-3-da-yin-fu-yin"></a>

除了纽鲁诗楼或图书馆，一般太古最快的打印地应该是 KKL 2F 的打印机和 Bloomberg 打印机，都可用 uprint，非常方便快捷。至于 Hall 内，6F 已经添置了黑白打印机。

### F 活动 & 相关设施 <a href="#f-huo-dong-xiang-guan-she-shi" id="f-huo-dong-xiang-guan-she-shi"></a>

活动室 & 健身

### 1. 活动室 <a href="#id-1-huo-dong-shi" id="id-1-huo-dong-shi"></a>

Hall 内 6 楼有 function room，有一架钢琴和一个练舞房。

### 2.健身和运动 <a href="#id-2-jian-shen-he-yun-dong" id="id-2-jian-shen-he-yun-dong"></a>

最近的健身房在百周年 Jockey Club Tower 3/F，步行 15 分钟。不过太平山还是随时对你开放的。

### 3.Hall Team <a href="#id-3hall-team" id="id-3hall-team"></a>

有一个 Hiking Club，纯内地生组织，每周六晚 19:30 爬太平山，可以认识很多内地小伙伴，和他们谈笑风生，还能刷 participation 用于 readmission，岂不美哉。当然，Hall 内的 sports team 等其他本地同学较多的组织同学们也可以根据兴趣踊跃加入，本地同学们都非常 nice，大家可以试着勇敢结交 Local 朋友，体验完整 Hall Life!

### G Readmission 考核标准 <a href="#greadmission-kao-he-biao-zhun" id="greadmission-kao-he-biao-zhun"></a>

不论是本地生或非本地生，都需要在每年四月通过 HKU Portal 提交续住申請。从 2023-24 年起，申请人需要具备 CGPA>=2.0 的学业成绩。

每年波动较大，但相比较而言可以说是踢人少的 Hall 了。基本上参加一个 team 或者一个 club，每周去去训练，就可以满足 contribution 的要求。日常没事儿和 local 友好地打打招呼，吐吐槽尬聊日常。也不一定要谈笑风生（嗯），放宽心做自己，自如地去应对所谓的 readmission 就行了。

第一次 apply 不成功，也可以在之后的 appeal 过程中再次申请。一言以蔽之，只要尽到份的责任，大部分内地生并不会觉得太古的 readmission 过分严苛。

### H 其他补充 <a href="#h-qi-ta-bu-chong" id="h-qi-ta-bu-chong"></a>

太古堂是校内宿舍，所以访客登记要求较校外更加严格。需要抵押宿舍学生的学生卡和访客的身份证件。

前往太古堂 Lobby 一般需要爬 3 层楼梯。如果有大件行李或者身体疲乏的话可以在方树泉文娱中心 G 层搭电梯。方法是来到电梯间后拿起电话随便拨一个数字即可接通太古的 reception，他们会帮你叫电梯下来。

### I 机场至 Hall 线路 <a href="#i-ji-chang-zhi-hall-xian-lu" id="i-ji-chang-zhi-hall-xian-lu"></a>

### 1. 香港机场（推荐） <a href="#id-1-xiang-gang-ji-chang-tui-jian" id="id-1-xiang-gang-ji-chang-tui-jian"></a>

a. 乘坐巴士 A10 → 在西宝城站/石塘咀市政中心站下车 → 进入地铁通道 → 地铁 A 出口 → 步行到达（约 1.5 小时，45 港币）

b. 乘坐机场快线 $$→$$ 香港站 $$→$$ 步行至中环站 $$→$$ （坚尼地城方向）在香港大学站下车 $$→$$ A2出口 $$→$$ 步行到达（约50分钟，100港币）

c. 乘坐 S1/S56 → 东涌站 → 乘坐东涌线到香港站 → 同 b) (1 小时, 大概 30 港币)

d. 搭乘的士前往，花费约 400HKD。

### 2. 深圳机场 <a href="#id-2-shen-zhen-ji-chang" id="id-2-shen-zhen-ji-chang"></a>

b. 在深圳机场地铁到后海/登良站 → 打车到深圳湾口岸 → 深圳湾口岸过关 → 过完关找到 B3X/B3 巴士（事先在环岛中港通购买深圳湾直达上环的巴士较优，详情自行搜索小红书攻略） → 在屯门官立中学站下车 → 乘坐 962X 到港澳码头干诺道中下车 → 乘坐地铁到香港大学 （约 3-3.5 小时，50-60 元左右，可以一路看风景的路线，但是有行李和初来乍到不c. 从深圳机场 16 号出口搭乘 m590 号大巴到深圳机场码头→进大厅等候上船（船票可在公众号“深圳机场码头”提前购买，票价根据舱位不同由 90-250 元不等）→过香港海关后达到香港中港城→步行至尖沙咀站，搭乘荃湾线至中环站下车，转港岛线，在香港大学站下车（约 2 小时 30 分钟，很独特的体验，但是班次稀疏，需要注意时间点）

推荐）

### J 从太古出发前往教室 <a href="#j-cong-tai-gu-chu-fa-qian-wang-jiao-shi" id="j-cong-tai-gu-chu-fa-qian-wang-jiao-shi"></a>

校内上课就是方便，到梁銶琚（商学院）只要 3 分钟，到徐展堂楼只要一分钟（其实下楼就是…），到本部大楼只要五分钟。不过去百周年校园可能需要十五到二十分钟喔。
