# 李国贤堂入住指南

## 一、基本信息 <a href="#a-ji-ben-xin-xi" id="a-ji-ben-xin-xi"></a>

### 1. 位置 <a href="#id-1-wei-zhi" id="id-1-wei-zhi"></a>

李国贤堂（Simon K. Y. Lee Hall, 也称 SKYLEE、Lee Hall）位于校内，紧邻香港大学西闸。

![](https://cdn-mineru.openxlab.org.cn/result/2026-06-22/18fb3202-fbe3-4d67-83bf-1bce44b0fe70/b260e1a1ca886c7822f1b470a582d8e3d822bc92726a57ef5d0a46d4d04b7d30.jpg)

### 2. 性别构成 <a href="#id-2-xing-bie-gou-cheng" id="id-2-xing-bie-gou-cheng"></a>

男女混住：

* 男生层：1/F, 5/F Long Wing, 6/F Long Wing, 7/F, and 8/F;&#x20;
* 女生层：2/F, 3/F, 4/F, 5/F Short Wing, and 6/F Short Wing.&#x20;

### 3. 室友背景 <a href="#id-3-shi-you-bei-jing" id="id-3-shi-you-bei-jing"></a>

从2023年起，为了促进交流融合，港大校委会决定在新学年将内地新生安排与本地生或者国际学生做室友。宿舍办公室将为入住两人或三人房的新入住宿生配对室友，务求本地生要和非本地生，包括海外和内地生住同一间房。留宿第二年起可以自行选择室友或者根据各室友（但Hall内部安排确定新一般情况下只能满足大部分同学的诉求，不能保证百分之百满足）。新生最初默认分到双人间，单人间需要向 Hall Office 写邮件提出申请（如果因为身体原因需要单人间，则必须提供医生开具的证明。任何时候均可提出申请，需于 waiting list 等候）。学期中如果有空床位也可以申请调换，Hall Office 会酌情考虑。

## 二、居住概况 <a href="#b-ju-zhu-gai-kuang" id="b-ju-zhu-gai-kuang"></a>

房间&床&家具

### 1. 房间类型 <a href="#id-1-fang-jian-lei-xing" id="id-1-fang-jian-lei-xing"></a>

除Tutor 的房间外都是双人间。

### 2. 房间尺寸 <a href="#id-2-fang-jian-chi-cun" id="id-2-fang-jian-chi-cun"></a>

约 3 x 4 m。

### 3. 卫生间＆浴室 <a href="#id-3-wei-sheng-jian-yu-shi" id="id-3-wei-sheng-jian-yu-shi"></a>

每层有卫生间及浴室，浴室以隔断分开，提供淋浴。

### 4. 床 <a href="#id-4-chuang" id="id-4-chuang"></a>

床的尺寸：90 x 210 cm。提供床垫（8cm厚），自己需要准备床单，枕头，被子，被套。如觉得床垫太薄可以自己带一个薄床垫叠在上面。床品可以在惠康超市、西宝城里其他卖床上用具的店、西环一些街边的商店以及宜家家居买到。

### 5. 家具 <a href="#id-5-jia-ju" id="id-5-jia-ju"></a>

房间内每人各有一张床，一个带架子的书桌，一个衣柜和一个矮柜（详情在下文中介绍）。

每个房间配备分体式空调，温度可调，部分房间还有电风扇。使用空调需要收费，同学需要自行在每层楼的自主缴费机为自己房间的空调充值，只支持刷八达通。

### 6. 水电 <a href="#id-6-shui-dian" id="id-6-shui-dian"></a>

房间24h不断电、不断网；不单独收取电费或网费。楼层有免费的直饮水接水处和开水器。

## 三、衣服相关 <a href="#c-yi-fu-xiang-guan" id="c-yi-fu-xiang-guan"></a>

### 1. 洗衣、烘干 <a href="#id-1-xi-yi-hong-gan" id="id-1-xi-yi-hong-gan"></a>

有洗衣机、烘干机，衣服洗完不想烘干也可以在9楼天台以及自己房间的窗台晾干（需自备晾衣架）。洗衣机和烘干机都位于9楼，刷八达通付款，洗衣机使用一次7HKD，烘干机为5分钟花费1HKD，视衣物情况一次需花费约6HKD到10HKD。一次可以处理约一周的衣服。

另，出于卫生考虑，建议自备洗衣袋、晾衣用衣架和夹子；洗完/烘干完后请及时取走衣物，避免自己的衣物被下一位使用者投入公共洗衣袋中。

### 2 衣物储存 <a href="#id-2-yi-wu-chu-cun" id="id-2-yi-wu-chu-cun"></a>

衣柜尺寸：大约 58 × 80 × 210cm。

床底下有三个抽屉（部分床设计成了五个）可以放东西（每个大约 60 × 90 × 20cm），以及有一个可以移动的矮柜（也由三个抽屉组成，整体约 60 × 50 × 60cm）。

需要自备衣架（晾衣服及在衣柜里悬挂大衣等）。

## 四、饮食概况 <a href="#d-yin-shi-gai-kuang" id="d-yin-shi-gai-kuang"></a>

### 1. 附近餐厅 <a href="#id-1-fu-jin-can-ting" id="id-1-fu-jin-can-ting"></a>

Hall就在学校内，所以去学校内的餐厅都很方便。楼下即有星巴克等，最近的餐厅是SU餐厅。去校外的餐厅也很方便，地铁通道口离Hall步行一分钟，通过地铁站通道可以去校外的很多好吃的地方。

### 2. Pantry（即公用小厨房） <a href="#id-2pantry-ji-gong-yong-xiao-chu-fang" id="id-2pantry-ji-gong-yong-xiao-chu-fang"></a>

每一层有一个Pantry，公用的器具有电磁炉、锅、微波炉、一些餐具、冰箱、调料（包括油），部分楼层配有烤箱。每一层有三个冰箱，有冷藏及冷冻。可以携带一个小平底锅或煮锅，因为有些公用的锅可能不够干净。餐具也可以准备自己用的。买做饭材料最方便的是西宝城（地铁 C2 出口，距 Hall 步行不超过 10 分钟）里的惠康超市以及B2出口附近的佳宝。校内也有一个百佳超市，但没有蔬菜，有少量水果及牛奶等。

### 3. 自动售货机 <a href="#id-3-zi-dong-shou-huo-ji" id="id-3-zi-dong-shou-huo-ji"></a>

在Hall内UG3层有卖零食和饮料的自动售货机。Hall所在的综合大楼也有很多自动售货机。

## 五、学习环境 <a href="#e-xue-xi-huan-jing" id="e-xue-xi-huan-jing"></a>

### 1. 书桌 <a href="#id-1-shu-zhuo" id="id-1-shu-zhuo"></a>

尺寸约100 x 60 cm，配备照明灯，上方有 2层短隔板1层长隔板，可以放书和其他杂物。有一堵配图钉的墙可以挂一些纸、草稿、笔记、轻型挂件。

### 2. 自习室 <a href="#id-2-zi-xi-shi" id="id-2-zi-xi-shi"></a>

Hall内平时无自习室，可以去图书馆或智华馆等自习。考试期间 UG3 的 Common Room会开放为二十四小时自习室。

### 3. 打印 &复印 <a href="#id-3-da-yin-fu-yin" id="id-3-da-yin-fu-yin"></a>

Hall内无打印设备，可在KB打印店、学校智华馆或图书馆打印和复印。

## 六、活动＆相关设施 <a href="#f-huo-dong-xiang-guan-she-shi" id="f-huo-dong-xiang-guan-she-shi"></a>

### 1. 活动室

Hall内有一个Common Room供举行活动等用（位于 UG3 层），一个较大的平台可以练球（篮球，羽毛球等），以及一个Band房供乐队排练用。Common Room有一架钢琴。在同一层楼还有一个桌球室，也是party room，可以刷学生卡进入。

### 2. Hall Team <a href="#id-2-hall-team" id="id-2-hall-team"></a>

有足球(仅限男生)、篮球、网球、羽毛球以及桥牌等各种活动队，通常内地生可以零基础加入。

### 3. Hall 内其他活动 <a href="#id-3hall-nei-qi-ta-huo-dong" id="id-3hall-nei-qi-ta-huo-dong"></a>

Hall 内每个学期会有 1 次 High Table Dinner；此外，会有 SKYERS Enrichment Programmme 的活动，意在丰富同学们的课余生活（同时提供 Readmission 中的 Contribution Score

## 七、Readmission <a href="#g-readmission" id="g-readmission"></a>

不论是本地生或非本地生，都需要在每年四月通过 HKU Portal 提交续住申请。从 2023-24 年起，申请人需要具备 CGPA ≥ 2.0 的学业成绩。

李国贤 Readmission。不过，readmission 的情况每年偶有变化，需以当年为准。整体上，Readmission 基本上不会面试。

## 八、前往李国贤 <a href="#h-qian-wang-li-guo-xian" id="h-qian-wang-li-guo-xian"></a>

### 1. 香港机场出发 <a href="#id-1-xiang-gang-ji-chang-chu-fa" id="id-1-xiang-gang-ji-chang-chu-fa"></a>

a) 乘坐巴士A10 → 在西宝城站/石塘咀市政中心站下车 → 进入地铁通道 → 地铁A2出口 → 到达 （约1.5小时）

b) 乘坐机场快线到香港站 → 步行至中环站 → 乘坐港岛线在香港大学站下车 → A2出口 → 到达 （约50分钟）

### 2. 深圳机场出发 <a href="#id-2-shen-zhen-ji-chang-chu-fa" id="id-2-shen-zhen-ji-chang-chu-fa"></a>

a) 在深圳乘坐跨境大巴（往上环，单程约120元），在深圳机场买票上车 → 深圳湾口岸过关 → 过完关找到去往上环的大巴 → 在上环港澳码头下车 → 乘坐地铁港岛线到香港大学站/打车 （约2小时）

b) 从深圳机场坐地铁（罗宝线）到罗湖站 → 在罗湖口岸过关 → 乘坐东铁线，在红磡站下车，转屯马线，在尖东站下车，步行至尖沙咀站，转荃湾线，在中环或金钟转港岛线到香港大学站（约3.5小时）

c) 从深圳机场坐地铁11号线到达福田站，换乘高铁到达香港西九龙站

3 高铁香港西九龙站出发

a) 乘坐巴士 970/970X，在香港大学西闸站下车，由地铁 A 出口电梯进入港大。

b) 乘坐东涌线到香港站 → 步行至中环站 → 乘坐港岛线在香港大学站下车 → A2出口到达。

算上等车时间，两者差不多均为约半小时，非学生八达通价格也相近，约为12HKD（地铁学生八达通约半价）。
