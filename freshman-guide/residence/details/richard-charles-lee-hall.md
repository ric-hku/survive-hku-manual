# 利铭泽堂入住指南

### A. 基本信息： <a href="#a-ji-ben-xin-xi" id="a-ji-ben-xin-xi"></a>

### 1. 位置 <a href="#id-1-wei-zhi" id="id-1-wei-zhi"></a>

沙宣道6号A座，玛丽医院斜对面。所处地段不嘈杂，夜里也很安静，交通较便利，平时可乘坐大巴或校车前往学校，约10分钟到达。

位于沙宣道学生舍堂村(民间叫法称为四村。但在23年黄竹坑的新舍堂被港大官方命名为“赛马会第四学生舍堂村”后，沙宣道舍堂村可能会失去作为四村的民间叫法)。

### 2. 性别构成 <a href="#id-2-xing-bie-gou-cheng" id="id-2-xing-bie-gou-cheng"></a>

男女同hall不同层。

### 3. 舍友背景 <a href="#id-3-she-you-bei-jing" id="id-3-she-you-bei-jing"></a>

注:从2023年起, 港大校委会为了促进交流融合, 决定在新学年将内地新生安排与本地生或者国际学生做室友。CEDARS将为入住两人或三人房的新入住宿生配对室友, 务求本地生要和非本地生(海外生或内地生)住同一间房。留宿第二年起可以自行选择室友或者根据各Hall内部安排确定新室友(但一般情况下只能满足大部分同学的诉求, 不能保证百分之百满足)。新生最初默认分到双人间, 单人间需要向Hall Office写邮件提出申请(如果因为身体原因需要单人间, 则必须提供医生开具的证明。任何时候均可提出申请, 需于waiting list 等候)。学期中如果有空床位也可以申请调换, Hall Office会酌情考虑。

### B. 居住概况: 房间&床&家具 <a href="#b-ju-zhu-gai-kuang-fang-jian-chuang-jia-ju" id="b-ju-zhu-gai-kuang-fang-jian-chuang-jia-ju"></a>

### 1. 房间类型 <a href="#id-1-fang-jian-lei-xing" id="id-1-fang-jian-lei-xing"></a>

有双人间和单人间，新生一般住双人间居多，一年之后如果需要可以向楼主申请住单人间。宿舍有空调，可以在每层楼直接用八达通充值，使用很方便(建议一次少量充值，充值后无法退款）。

### 2. 房间尺寸 <a href="#id-2-fang-jian-chi-cun" id="id-2-fang-jian-chi-cun"></a>

双人间大概 $$3m × 4.5m$$ ; 单人间大概是双人间面积的一半。

### 3.床 <a href="#id-3-chuang" id="id-3-chuang"></a>

床大约0.9m×1.9m，提供有床垫和一个很薄的小pad。有床垫所以可以不准备褥子，但需要自行准备床单、被子和枕头。如果不方便从家带的话，学校附近有超市和家具用品店，或者可以从学校乘地铁去铜锣湾的宜家购买。注：双人间的床会比单人间的床大。

### C. 衣物相关: 洗衣机&衣柜 <a href="#c-yi-wu-xiang-guan-xi-yi-ji-yi-gui" id="c-yi-wu-xiang-guan-xi-yi-ji-yi-gui"></a>

### 1. 洗衣&烘干 <a href="#id-1-xi-yi-hong-gan" id="id-1-xi-yi-hong-gan"></a>

16楼有洗衣房，里面洗衣机烘干机各四台（有时候会有一至两台处于维修状态），八达通付款。洗衣一次收费4hkd，烘干每十分钟2hkd（通常需要一小时左右干透）。洗衣房外露天有固定的晾衣杆和晾衣绳，很方便，注意阳台风大，可以准备一些夹在晾衣绳上的夹子。

### 2. 衣物储存 <a href="#id-2-yi-wu-chu-cun" id="id-2-yi-wu-chu-cun"></a>

衣柜大概高2.2m、宽0.9m；上面的1.5m左右部分是衣柜，下面0.7m左右划分成3个抽屉。衣柜上面离天花板有一定距离，可以平放一个小行李箱。除此之外床下有三个抽屉，可以放鞋子或者杂物。需要自己准备衣架。

### D. 饮食概况:餐厅\&Pantry&711&售货机 <a href="#d-yin-shi-gai-kuang-can-ting-pantry711-shou-huo-ji" id="d-yin-shi-gai-kuang-can-ting-pantry711-shou-huo-ji"></a>

### 1. 附近餐厅 <a href="#id-1-fu-jin-can-ting" id="id-1-fu-jin-can-ting"></a>

Hall下面有一家餐厅Sandwich Club Kiosk，工作日营业时间为8:00-16:00，周六日及公共假期不开门。从宿舍走过一条天桥就是玛丽医院，玛丽医院里面有大家乐（中式快餐，价格与学校相近，味道很好，用学生卡可以享受7折左右的折扣）、Pacific Coffee和一家粥面馆。另外四村紧挨港大医学院校区，从hall出来沿着下坡走5分钟就到，校区内有Subway。

沿沙宣道下楼可以到数码港，步行时间约为三十分钟，有很多餐厅（麦当劳等）。平时可以叫外卖，一般送到四村外卖运费在30hkd左右，但是用KeeTa点外卖部分店家可以免运费。

### 2. Pantry <a href="#id-2-pantry" id="id-2-pantry"></a>

Hall内每层楼都有pantry，pantry里面有冰箱、微波炉、烤箱和电磁炉可以自由使用。其他设施可能楼层之间不太一样，比如有些楼层的厨具、餐具和调料需要自己准备，有些楼层则公用。

### 3.711便利店 <a href="#id-3711-bian-li-dian" id="id-3711-bian-li-dian"></a>

楼下有一家711(从早上七点到晚上十点，但下午有些时间段经常会暂停营业，可以留意店门口告示)，可以买到饭。

### 4. 自动售货机 <a href="#id-4-zi-dong-shou-huo-ji" id="id-4-zi-dong-shou-huo-ji"></a>

Hall的2楼有数个饮料自动贩卖机和1个零食贩卖机，价钱相对711便宜，但机器较老不太好用(碰到至少2次付了钱没拿到饮料的情况)。

### E. 学习环境: 书桌&自习室 <a href="#e-xue-xi-huan-jing-shu-zhuo-zi-xi-shi" id="e-xue-xi-huan-jing-shu-zhuo-zi-xi-shi"></a>

### 1. 书桌与自习室 <a href="#id-1-shu-zhuo-yu-zi-xi-shi" id="id-1-shu-zhuo-yu-zi-xi-shi"></a>

书桌大概60cm × 160cm，有一个电源和一个网线接口，上方有台灯(灯管式)。书桌下方侧面是柜子，带有三个小抽屉。灯管下书桌上前是可钉钉子的软木板，灯管上书桌顶部有两层书架。

四村离医学图书馆走路只要5分钟！医学图书馆环境好，人又少又安静，期中期末复习的时候不用跑去主校园和大家抢图书馆/自习室的位置，绝对是学习的好去处。

### 2. 打印&复印 <a href="#id-2-da-yin-fu-yin" id="id-2-da-yin-fu-yin"></a>

Hall的G层有打印复印扫描一体机，打印和扫描可以选择在自己的电脑做相应软件的安装(reception counter那里有安装光碟，或者可以上网安装)，也可以直接拿U盘去打印机打（目测只支持pdf格式）；支持八达通付款。

此外，医学图书馆也可以打印，八达通学生卡都支持。

### F. 活动 & 相关设施: 活动室 & 活动队 & 体育运动 <a href="#f-huo-dong-xiang-guan-she-shi-huo-dong-shi-huo-dong-dui-ti-yu-yun-dong" id="f-huo-dong-xiang-guan-she-shi-huo-dong-shi-huo-dong-dui-ti-yu-yun-dong"></a>

### 1. 活动室 <a href="#id-1-huo-dong-shi" id="id-1-huo-dong-shi"></a>

二楼有音乐室，里面有钢琴和架子鼓。

### 2. 活动队 <a href="#id-2-huo-dong-dui" id="id-2-huo-dong-dui"></a>

体育类的team有羽毛球，篮球，网球，乒乓球，足球，排球，手球，壁球，垒球，曲棍球，田径运动和水上运动。我们Hall的体育类team相对比较水，可以请假，训练也chur，想要加入的话一般随时都可以。

文化类的活动有桥牌，合唱，辩论，话剧和舞蹈队。多数team以学年为单位训练、排练或表演。

### 3. 体育运动 <a href="#id-3-ti-yu-yun-dong" id="id-3-ti-yu-yun-dong"></a>

Stanley Ho体育中心，有健身房，网球场，游泳池，羽毛球场，篮球场，游泳馆，曲棍球场棒球场，还有港大唯一的操场。从四村沿小道走下去大概十五分钟，沿途海景，空气清新。平时也有校车可以到，是很多 hall team 的训练场所。

### G. Readmission考核标准 <a href="#greadmission-kao-he-biao-zhun" id="greadmission-kao-he-biao-zhun"></a>

利铭泽堂历史上很少quit人，以往并不必须要求参加hall里的活动。

不过2017年开始实行新的制度，部分通过readmission的堂友需要签Conditional offer(即如果下一学年第一学期表现不好第二学期就有被踢的可能性)。自2021年起对部分学生实施面试考核。这意味着hall对非本地生的要求更严格了，今后想要留下可能要至少参加hallteam, 做一定的contribution。根据2024年新出的readmission计分标准，50%为Need score，50%为Merit score。Need score用于评估同学们的住宿需求，主要根据学校离家距离决定，非本地生在此部分分数为满分。Merit score中50%为学术成绩（GPA），50%为contribution和tutor、层友评分等。

### H. 交通指南 <a href="#h-jiao-tong-zhi-nan" id="h-jiao-tong-zhi-nan"></a>

### 1.往来香港机场 <a href="#id-1-wang-lai-xiang-gang-ji-chang" id="id-1-wang-lai-xiang-gang-ji-chang"></a>

最方便:直达巴士A10(机场－玛丽医院站)。车次约半小时1班(可实时查阅巴士网站)程约60 - 75分钟，车资48港币。

除的士最快:机场快线转巴士(机场－港铁香港站B2口／香港大学站A口－玛丽医院站)。总时长约1小时，总花费110港币之内。

最便宜: 将上一条线路中的机场快线段(机场至香港站)改为巴士S1线 + 港铁东涌线, 于东涌站转乘。总时长约1小时45分钟, 总花费约20港币(学生八达通)/30港币(成人八达通)。

最土豪 & 最舒服(行李多):的士。车程约30 - 50分钟，车资约300港币。夜间(00:20 - 06:20):通宵机场巴士NA10(机场 - 玛丽医院站)返hall。总时长约1小时，总花费约80港币。

注: 以上所有时间估计均基于交通状况良好且交通工具之间转换顺利的假设, 请合理预留时间; 以上路线均可反向。

### 2.往来深圳机场 <a href="#id-2-wang-lai-shen-zhen-ji-chang" id="id-2-wang-lai-shen-zhen-ji-chang"></a>

跨境巴士: 深圳机场 – 上环港澳码头, 之后(无须过马路!)在巴士站可乘城巴7号巴士至玛丽医院;

地铁为主，巴士为辅：深圳机场－（机场线）－车公庙站－（宝安线）－罗湖口岸－（东铁线）－九龙塘站－（观塘线）－旺角站E出口－(970／970X)－玛丽医院站。亦可选择深圳福田口岸／香港落马洲口岸过关，需于宝安线会展中心站转龙华线至口岸，搭乘东铁线后同上。亦可选择香港站转巴士，需于旺角站转荃湾线至中环／香港站，之后同上。特殊旅程：深圳机场乘船（每日两班）至上环港澳码头，之后同前述。夜间：搭乘的士经皇岗口岸过关。

### 3.往来深圳北站 <a href="#id-3-wang-lai-shen-zhen-bei-zhan" id="id-3-wang-lai-shen-zhen-bei-zhan"></a>

跨境巴士: 深圳北站－上环港澳码头，之后同前述。

地铁: 深圳北站 – (龙华线) – 深圳福田口岸／香港落马洲口岸, 搭乘东铁线后同前述。

### 4. 来往香港西九龙 <a href="#id-4-lai-wang-xiang-gang-xi-jiu-long" id="id-4-lai-wang-xiang-gang-xi-jiu-long"></a>

巴士(可直达):(970/970X)柯士甸-玛丽医院

### 5. 往来学校 <a href="#id-5-wang-lai-xue-xiao" id="id-5-wang-lai-xue-xiao"></a>

校巴: 工作日全天及周六上午运营，班次表见校方网站／巴士站告示／RIC微信公众号。车资2港币，时间约10分钟。

巴士:4/4X/7/30X/37B/37X/71/90B/91:香港大学西闸－玛丽医院／玛丽医院－山道（港大地铁C1出口）。40/40M/94:香港大学西闸－玛丽医院／玛丽医院－香港潮商学院(经天桥至港大地铁A2出口）、英皇书院(港大东闸)。970/970X/973玛丽医院至香港大学段因车资较高不予推荐。以上线路除30X外均经何东夫人堂站。(玛丽医院站巴士除A10均可到达香港大学附近;港大西闸巴士除23/103均可到达玛丽医院)

小巴:55:(去四村)新院有落、坐到终点。8/28:(去四村)转弯有落、沙宣道有落／(去学校)地铁站有落。注:“有落”是粤语“有人要下车”的意思，读作“油咯”，香港乘小巴快到站需要和司机说明自要下车了。

以上非校巴方式车资约 5 港币，全程时长约 15 分钟。
