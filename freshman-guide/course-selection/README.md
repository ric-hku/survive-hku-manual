# 选课指南

{% hint style="info" %}
本文尽可能选用 [HKU Standard Terminology / 香港大學校內用辭匯編](https://cpao24.hku.hk/cpao/terminology) 中的官方中译。

然而，Programme 和 Curriculum 的中译都是 “课程”。为避免混乱，同时考虑到内地用语习惯，本文**称 Programme 为 “专业”**。

此外，Course 的中译是 “科目”。考虑到内地用语习惯，本文译为 “课程”。
{% endhint %}

## 一、课程结构

学校的每个专业（Programme）都提供了 Degree Regulations and Course Descriptions（课程资料与规则）。这可以在以下网站找到：

{% embed url="https://www4.hku.hk/pubunit/drcd/" %}

或者，也可以在自己学院的官网上找到相关信息：[主要部门和学院指南](../campus-life/offices-and-faculties.md)。

一般来说，每个本科项目会有 Regulation（规则 / 规定）和 Syllabus（课程 / 大纲）。

{% hint style="info" %}
有的学院会将 Regulation（规则 / 规定）和 Syllabus（课程 / 大纲）合并到一个文档。

有的学院也会单独列出 Curriculum Structure（课程结构）。
{% endhint %}

一般而言，毕业所要求的课程结构如下：

### 2. Syllabus 大纲

在 Syllabus 之中，会列出每个可以选择 / 必须选择的课程的简介（Description）、考核方式（Assessment）。可以在这里大致了解课程内容。

## 二、学分 Credits

一般来说，本科四年的专业要求修满 240 学分；本科五年的专业要求修满 300 学分。

一个课程一般为 6 学分；少数学时、Workload 等偏小的课程为 3 或 0 学分；全年课程（Full Year Courses）一般为 12 学分，每学期按 6 学分计算（如为 6 学分，则每学期 3 学分）。

学校建议一学期修读 24 - 30 学分的课程；一学期最多可以修读 36 学分的课程。

* 如果想在一学期修读 36 学分以上（或一学年 72 学分以上），这称作 Overload；
* 如果想在一学期修读 24 学分以下（或一学年 48 学分以下），这称作 Underload；
* Overload、Underload 都需要向学院申请许可。可能需要提供相应理由。

{% hint style="info" %}
夏季学期 Summer Semester 除外：非必须，且最多只能选修 2 门课程。
{% endhint %}

## 三、主修 / 副修 / 专业必修 Major / Minor / Professional Core

### 1. 主修和副修 Major & Minor

一个主修（Major）一般包含 72 - 96 学分；一个副修（Minor）一般包含 36 - 48 学分。

#### 1.1. 第一主修 1st Major

有些专业，如 BA、BSc、BSocSc 等，只会限定第一主修需要来自所属学院，而并不会限定具体的第一主修。对于这些学生，可以阅读 Syllabus 了解可以选择的第一主修。

有些专业，如 BASc(AppliedAI)、BEng(ME) 等，则已经限定了第一主修。

一个主修中会包含一个总结性学习体验（Capstone Experience），相当于毕业项目。

#### 1.2. 第二主修和副修 2nd Major & Minors

除了第一主修，同学还可以利用自己的自由选修学分（Free Electives）修读第二主修或副修。

可以修读的第二主修或副修及具体要求，见下文 “1.4. 主修、副修列表及介绍”。

{% hint style="info" %}
主修、副修只会显示在毕业后发出的成绩单、Academic Attainment Profile (AAP) 上，而不会显示在毕业证明、学位证书上。
{% endhint %}

#### 1.3. 主修、副修的申报 Declare Major/Minor

一般来说：

* 大二的第一学期可以开始 Declare 主修、副修；
* 大三的第一学期必须 Declare 主修、副修；
* 最后一年的第一学期（含 / 不含取决于学院）后不能再修改主修、副修。

不同学院的具体要求可能有所不同。如有疑问，可咨询所属学院。

{% hint style="info" %}
理学院的学生可以选择在大一 Declare 主修、副修。
{% endhint %}

只有在特定时间段可以 Declare 主修、副修：

* 选课前（一般为 8 月 1 日起）；
* 选课期间；
* Add/Drop Period。

### 2. 专业必修 Professional Core

有些专业，如 LLB 等，并不采用第一主修的形式来安排专业必修课。这时，Syllabus 中会称之为 Professional Core。

其余部分，包括主修、副修等，与其他专业没有很大的差别。

## 四、Lecture 与 Tutorial

### 1. Lecture 讲课

即一般的授课。同学在系统中排课时，看到的一般都是 Lecture 的时间。

#### 1.1. Subclass

部分课程为容纳更多同学，会提供多个 Subclass 供大家选择。

每个 Subclass 的时间、地点和授课教师有可能不同。

可以根据自己的排课时间、教师偏好等进行选择。

### 2. Tutorial 导修课

一种配合大班 Lecture 的小班辅导与讨论课；一般由助教（Teaching Assistant, TA）进行。

Tutorial 一般在开学后选择。由于形式可能有所不同，授课老师会在课上介绍选择 Tutorial 的方法及开始时间。

为了适应不同同学的课表，Tutorial 一般有比较多的时间段可供选择。因此，考虑选课时不需要考虑 Tutorial。

{% hint style="info" %}
并不是每个课程都会有 Tutorial。

* 有的课程本身是小班课，因此不需要设置 Tutorial；
* 有的课程则会直接选择 Lecture 的一段时间来进行 Tutorial。

对于上述情况的课程，不需要选择 Tutorial。
{% endhint %}

## 七、常见问题与解答

### Q1. 现在是暑假期间。我是不是只需要选择第一学期的课程？

第二学期开始前，不再单独安排选课时间，而只有 Add/Drop Period。因此，在暑假期间的选课期间，必须完成两个学期的选课。

但是，如果第二学期的部分课程需要第一学期的课程作为前置条件，则可以把这部分课程留到第二学期的 Add/Drop Period 再进行加课操作。这是因为只有通过（Pass）前置课程，才能成功选上后续课程。

### Q2. 学院会不会给我排课？

仅部分学院（如商学院）会为大一新生排好专业课。

学院会在选课前排好 Subclass，并显示在同学们的临时课表中。之后同学们只须自主选择即可。

### Q3. 正式选课期间结束后，是不是不能再修改选课了？

不是。

每个学期的最初 2 周一般为 Add/Drop Period（加 / 退选期），意在让同学们了解课程内容，并再次决定是否需要修改选课。

在此期间，选课系统会一直开放（除了 Suspension Period），同学仍可以继续调整选课（包括加课、退课）。

本学年 Add/Drop Period 的具体时间，详见：[2026 – 27 校历、假期](../../appendices/2026-27-calendar.md)。

### Q4. 有的课程对 HKDSE 某科目成绩有要求，而我不是通过 HKDSE 入学的。我怎么选这些课程？

这些课程一般是中文学院（中国语言文学）、英文学院（ENGL、DRTP 课程）或理学院的。

如果想选择这些课程，可能需要特殊申请。

有关高考、国际体系考试等如何对应 HKDSE 的考试成绩，详见：[部分课程修读要求](enrollment-requirements.md)。

### Q5. Tutorial 要如何选择？我要在排课、选课时一并选择 Tutorial 吗？

Tutorial 一般在开学后选择。

由于形式可能有所不同，授课老师一般会在课上或 Moodle 中介绍选择 Tutorial 的方法及开始时间。

为了适应不同同学的课表，Tutorial 一般有比较多的时间段可供选择。同学可以在选课获批或开学后了解可供选择的时间段。

因此，考虑选课时不需要考虑 Tutorial。

以下课程可以在对应的网页看到选课情况：

* CAES1001：[https://sweb.hku.hk/ccacad/eng/enrol\_stat.html](https://sweb.hku.hk/ccacad/eng/enrol_stat.html)

### Q7. 课程编号和 Subclass 编号有什么含义？

以 ACCT1101-1A 为例：

* ACCT1101 是课程编号：
  * ACCT 表示学科 / 领域：Accounting 会计学；
  * 1101 是学科 / 领域中的课程编号。
  * 部分课程会标注 “FY”，如 ITAL1003FY，表示是持续一年两个学期的全年课程。

{% hint style="info" %}
一般来说，首位数字整体上遵循下列规律：

* 1 表示某个大类 / 学科中的基础课程，也可作为该领域的体验性课程；
* 2 表示某个学科中的基础课程，作为继续在该学科学习的基础；
* 3 表示某个学科中更为进阶的课程；
* 4 表示某个学科中最为进阶的课程，通常是毕业年份修读的总结性学习体验（Capstone Experience）。

也有的学科 / 领域首位数字只采用 1 – 3；这时，3 表示最为进阶的课程。

不过，每个学院 / 学系都会有自己的安排方式。因此，上述规律仅供参考。

此外，首位数字 6 – 8 表示为研究生开设的课程（部分也会开放予本科生修读）。

另外，CAES 课程、中文增补课程、Common Core 课程、AILT 课程等有自己的编码规律。
{% endhint %}

* 1A 是 Subclass 编号：
  * 首位字符表示 Subclass 开设的时间：
    * 1 表示第一学期；
    * 2 表示第二学期；
    * S 表示夏季学期；
    * F 表示全年。

### Q9. 双主修（Double Major）与双学位（Double Degree）有何区别？

修读双主修（Double Major）的同学，是利用自己的自由选修学分（Free Electives）修读第二主修。

可以修读的第二主修列表：[List of Majors by Faculties/Subjects](https://aas.hku.hk/list-of-major/)。

所修读的主修只会显示在毕业后发出的成绩单、Academic Attainment Profile (AAP) 上，而不会显示在毕业证明、学位证书上。

修读双学位（Double Degree）的同学，是在入学时专业（Programme）为双学位项目的同学。

以单一学位项目入学的同学，非经转专业（Internal Transfer），不能获得第二个学位。
