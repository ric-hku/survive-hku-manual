# 利玛窦宿舍入住指南

### A. 基本信息 <a href="#a-ji-ben-xin-xi" id="a-ji-ben-xin-xi"></a>

### 1.位置： <a href="#id-1-wei-zhi" id="id-1-wei-zhi"></a>

薄扶林道 93 号，从学校西侧百周年校区出校后步行 5 分钟即可到达。位于一村（薄扶林道 91 号）附近。

### 2. 宿位&性别构成: <a href="#id-2-su-wei-xing-bie-gou-cheng" id="id-2-su-wei-xing-bie-gou-cheng"></a>

全宿舍共 131 人，纯男生，所有房间都是带阳台的单人间。

### 3. 主要建筑： <a href="#id-3-zhu-yao-jian-zhu" id="id-3-zhu-yao-jian-zhu"></a>

由七个互相连通的 block 围绕 dining hall 构成。其中 5 个 block 用于学生住宿，另外两个分别是教堂和 Warden 住所。宿舍门口是一个宿舍专用篮球场。

### 4. 宿舍背景: <a href="#id-4-su-she-bei-jing" id="id-4-su-she-bei-jing"></a>

1929年由耶稣会成立。作为non-university-administered hall之一，利玛窦宿舍不受P-1政策（可参考其他文件）影响，并且如需gap，期间仍可以住hall。\
宿舍活动由宿生会（RHSA）组织。

### B. 居住概况 <a href="#b-ju-zhu-gai-kuang" id="b-ju-zhu-gai-kuang"></a>

### 1. 房间概况： <a href="#id-1-fang-jian-gai-kuang" id="id-1-fang-jian-gai-kuang"></a>

Ricci Hall 一共有 3 种房型，其中两种大房型数量较少，基本为宿生会成员及高年仙居住（仙制是 local 的传统，一般在舍堂居住时间越长等级越高）。普通房型由一个约 2 &#x7C73;_&#x33;.5 米的房间和一个约 1.5 &#x7C73;_&#x31;.5 米的阳台组成，阳台朝北是海景房，朝南是楼景房。

### 2. Corridor: <a href="#id-2-corridor" id="id-2-corridor"></a>

Corridor 是 Ricci Hall 独有的称呼。不同于其他 hall，Ricci Hall 每两个 block 共用一个楼梯，每半层一个 corridor，分别向两个 block 延伸。每个 block 有 3 至 4 个 corridor，相当于最高楼层为 4 层。每个 corridor 居住 6 人或 8 人，所以相比一般宿舍每层楼 20 多人的情况，Ricci Hall 居住环境会比较安静。

### 3.房间设施： <a href="#id-3-fang-jian-she-shi" id="id-3-fang-jian-she-shi"></a>

房间内有一张约 0.9 米\*2 米，高约 1 米的床，床上方是置物架，床下方是六个大柜子；一张约书桌；一个嵌入式衣柜；一个窗式空调。通过一扇玻璃门可以进入阳台。

### 4. Pantry: <a href="#id-4-pantry" id="id-4-pantry"></a>

Ricci Hall 的 pantry 很小，摆放冰箱和一个微波炉后，仅供一个人站立。所以 corridor 内没有像其他 hall 一样在 pantry 内吃饭打麻将等聚会的习俗，corridor 通常非常安静。

### 5. 洗浴设施： <a href="#id-5-xi-yu-she-shi" id="id-5-xi-yu-she-shi"></a>

每个 corridor 有一个厕所，里面有两个水池，两个浴室及两个厕所隔间。

每个 block 有一个饮水机，位于中部 corridor。

### C. 饮食 <a href="#c-yin-shi" id="c-yin-shi"></a>

Dining Hall 位于各 block 中间的地下，摆放了九张圆桌供大家就餐。宿舍厨房在周中会提供早中晚餐，每餐有 4 种选择，每天更换菜单。

Dining Hall 内有一个自动售货机，售卖饮料。

### D. 洗衣相关 <a href="#d-xi-yi-xiang-guan" id="d-xi-yi-xiang-guan"></a>

old block 地下有一个洗衣房，拥有两个洗衣机（1、2、5 元硬币）和一个烘干机（只能用 5 元硬币），2024 年暑假更新的价格为洗衣 8 元港币一次，烘干 5 元港币 14 分钟。因为烘干机经常排队，很多人会将衣服拿到阳台上晾干。

### E. 活动 <a href="#e-huo-dong" id="e-huo-dong"></a>

作为一个传统男 hall，Ricci Hall 体育氛围极其浓厚，打球是 hall 内最主要活动。体育成绩和参与度是 admission 及 re-admission 的重要指标，各种球类都有球队且竞争力强。

高桌晚宴（High Table Dinner）：每年 6 次，在宿舍 Dining Hall 举办，所有宿生必须参加，流程简洁，食物美味。

其他活动有 Gong Fight, Champfight dinner, Champion day, Christmas Run 等等，大家可以自行搜索。

### F. Re-admission 考核标准 <a href="#freadmission-kao-he-biao-zhun" id="freadmission-kao-he-biao-zhun"></a>

不论是本地生或非本地生，都需要在每年四月通过 HKU Portal 提交续住申請。从 2023-24 年起，申請人需要具备 CGPA>=2.0 的学业成绩。

需要参加运动队训练和比赛。相比于其他宿舍的同学因受学校强制的 $$44%$$ 的留hall率而苦于re-admission，Riccian几乎不会面临被踢的风险。一般来说只有个位数的人未能成功留宿。

### G. 费用 <a href="#g-fei-yong" id="g-fei-yong"></a>

全年住宿费为 24395 港币，餐费为 10600 港币，包含了 9000 港币的日常餐费和六次 htd 费用（与宿费一起上交）；900 港币的 RHSA membership fee。开学时需交 3200 港币押金。

### H. 交通 <a href="#h-jiao-tong" id="h-jiao-tong"></a>

### 1.香港机场出发 <a href="#id-1-xiang-gang-ji-chang-chu-fa" id="id-1-xiang-gang-ji-chang-chu-fa"></a>

a)在机场乘坐机场快线到达香港站（110RMB），在地铁站内步行至中环站换乘港岛线（坚尼地城方向）经过3站到达香港大学站，从C1出口出，沿着薄扶林道向上走30米左右到达赛马会第一舍堂村；

b)在机场地面运输中心乘坐城巴 A10（鸭脷洲总站方向），经过 6 站在西宝城站下车，经登山电梯上山后沿薄扶林道上行 20 米左右到达赛马会第一舍堂村；全程花费港币约 50 元；

c)搭乘的士前往，花费约300—400HKD。

### 2. 深圳机场 <a href="#id-2-shen-zhen-ji-chang" id="id-2-shen-zhen-ji-chang"></a>

在机场地面运输中心乘坐中港通巴士（票价 54RMB，经过深圳湾入关，有工作人员指引）到达上环下车（一般停靠在港澳码头），乘地铁港岛线（坚尼地城方向）经过 2 站到达香港大学站，C1 口出沿薄扶林道上行 30 米到达；或在港澳码头搭乘出租车，花费约 35—40HKD。

### 3. 从 Ricci 出发（Hall 至学校线路） <a href="#id-3-cong-ricci-chu-fa-hall-zhi-xue-xiao-xian-lu" id="id-3-cong-ricci-chu-fa-hall-zhi-xue-xiao-xian-lu"></a>

出 Hall 直接沿薄扶林道步行，经过地铁站（C 出口站）乘电梯进入百周年校区；或从地铁站里面穿行至 A 出口乘电梯直接进入校园（SU 平台）；或过马路直接走到 A 出口搭电梯进入校园，到达 A 出口若继续往前走则是 Main Building；或直接步行通过劲过桥进入百周年校园地下；通常步行到达校园一端的时间是 10 分钟，更远的教室需要预留更长的时间。

### 写在最后 <a href="#id-1-xie-zai-zui-hou" id="id-1-xie-zai-zui-hou"></a>

Ricci Hall 的居住条件可以算是 HKU 宿舍最顶尖的。地理位置方便，距离学校和地铁站都非常近。下楼即可到达食堂，无需下山觅食。

参加宿舍内活动会比较累，运动队训练量很大（比赛前会一周三次，每次7:00-8:30）。

目前宿舍内地同学比较少，大家如有兴趣，欢迎申请入住！
