# 大学堂入住指南

### 基本信息 <a href="#ji-ben-xin-xi" id="ji-ben-xin-xi"></a>

### 位置 <a href="#wei-zhi" id="wei-zhi"></a>

![image](https://cdn-mineru.openxlab.org.cn/result/2026-06-22/4ba5c319-d375-4a1a-8528-b4966861b8c2/536b76f2825d225efc58b9aa74aa018c30c242e2b0f97207dbd0b2042327ece4.jpg)

UHall位于薄扶林道144号，是除黄竹坑外距离香港大学本部最远的Hall。

### 宿位和性别构成 <a href="#su-wei-he-xing-bie-gou-cheng" id="su-wei-he-xing-bie-gou-cheng"></a>

根据官网信息，UHall共有107个宿位。仅限男生居住。

### 室友背景 <a href="#shi-you-bei-jing" id="shi-you-bei-jing"></a>

之前一般会安排内地生和内地生住，国际生和国际生住，以及交换生和交换生一起住。但为促进宿生间多元文化交流、增进舍堂凝聚力，新任 Warden 和新一届 Uhall StudentAssociation计划对对房间分配进行改革。所以新学期很可能将不同身份背景的宿生混合交叉分配房间。舍堂内环境非常包容多元，以Student Association成员组成为例，过去一年有多位 non-local 堂友加入了 UHall Student Association。

### 居住概况 <a href="#ju-zhu-gai-kuang" id="ju-zhu-gai-kuang"></a>

### 楼层安排和房间类型 <a href="#lou-ceng-an-pai-he-fang-jian-lei-xing" id="lou-ceng-an-pai-he-fang-jian-lei-xing"></a>

UHall也叫道格拉斯堡，是一座城堡，共三层。过去第一层主要给本地生住，非本地生（包括内地生，国际生和交换生）多住在第二第三层。但之后，楼层安排可能因新的房间分配制度而改变。房间大多数为四人间，少数二人间和单人间。

### 房间尺寸 <a href="#fang-jian-chi-cun" id="fang-jian-chi-cun"></a>

5m\*5.5m

### 卫生间＆浴室 <a href="#wei-sheng-jian-yu-shi" id="wei-sheng-jian-yu-shi"></a>

每层有公共的卫生间及浴室，每个单元以隔断分开，浴室全年全天候24小时提供热淋浴。

### 床 <a href="#chuang" id="chuang"></a>

床的结构为上床下桌，床的大小约为 210cm\*110cm，提供床垫，自己需要准备床单，枕头，被子等各种可能用到的床上用品（可以在到港后于宜家或日本城等地方购买）。

### 家具 <a href="#jia-ju" id="jia-ju"></a>

房间内每人各有一张床，一个自带台灯的书桌（会配一把椅子）以及一个衣柜（详情在下文中介绍），每个房间有三扇门，一扇门通向走廊，一扇门通向阳台（同层共用），最后一扇门是阳台门的木制风窗。

### 衣物相关 <a href="#yi-wu-xiang-guan" id="yi-wu-xiang-guan"></a>

### 洗衣＆烘干 <a href="#xi-yi-hong-gan" id="xi-yi-hong-gan"></a>

Hall内有两台洗衣机，两台烘干机；每个房间都有可以晾衣服的阳台（晾衣架需自备）；洗衣机和烘干机都在 1 楼，需要使用八达通支付；洗衣机一次 5 港币，烘干机每四分钟1.4 港币。

### 衣物储存 <a href="#yi-wu-chu-cun" id="yi-wu-chu-cun"></a>

衣为 100cm（宽）\*210cm（高），上层可以放置皮箱，同时书桌下也有带三个抽屉的柜子，书桌旁五层的储物格子可以放置杂物。衣柜里面一般不会提供衣架，需要自己购买。

### 饮食概况 <a href="#yin-shi-gai-kuang" id="yin-shi-gai-kuang"></a>

### 附近餐厅 <a href="#fu-jin-can-ting" id="fu-jin-can-ting"></a>

Hall内有餐厅，周一至周六全天供应三餐，可堂食可外带；周日供应午餐和晚餐，只可外带。一般早餐提供两种选择，价格约40港币；午晚餐各提供三种选择，价格约 55港币。离UHall约12分钟步行路程的地方有置富南区广场，里面有大快活、麦当劳、谭仔三哥米线、金记冰室，以及特色食档等餐厅，周末如果不去学校可以在那里解决吃饭问题。

### Pantry <a href="#pantry" id="pantry"></a>

Hall内有两个pantry，有各种电磁炉锅碗瓢盆调料以及冰箱等做菜的工具。原材料可以在学校附近买后带回UHall，或者在上文提到的置富广场的超市购买。不过需要注意的是，所有厨房内的厨具其实都是舍友暂时放在那的，所以用完后请一定要记得清洗干净和归还原位。 也可以自己准备相关厨具。

### 自动售货机 <a href="#zi-dong-shou-huo-ji" id="zi-dong-shou-huo-ji"></a>

Hall内有两台自动售货机。一台位于B层阅览室，销售饮料，只能使用八达通支付；另一台位于 A 层走廊尽头，销售零食与饮料，支持八达通、微信、支付宝和其他电子支付方式。

### 学习环境 <a href="#xue-xi-huan-jing" id="xue-xi-huan-jing"></a>

### 书桌 <a href="#shu-zhuo" id="shu-zhuo"></a>

书桌有140cm\*80cm，上方有放书的架子和照明灯。旁边有可以放书的柜子。

### 自习室 <a href="#zi-xi-shi" id="zi-xi-shi"></a>

Hall内三楼有带空调的图书馆，可以用作学习室。

### 打印＆复印 <a href="#da-yin-fu-yin" id="da-yin-fu-yin"></a>

Hall内有打印复印设备，需要使用实体八达通支付。与校内打印机使用方式不同。可通过USB存储设备有线传输或指定的软件无线传输需要打印的文档。

### 活动＆相关设施 <a href="#huo-dong-xiang-guan-she-shi" id="huo-dong-xiang-guan-she-shi"></a>

### 活动室 <a href="#huo-dong-shi" id="huo-dong-shi"></a>

Hall内有活动室，内有健身器材，台球桌，电视机以及迷你足球等设施。同时，Hall外有一个篮球半场以及两个网球场，步行两分钟即可到达。

### Hall内其他活动 <a href="#hall-nei-qi-ta-huo-dong" id="hall-nei-qi-ta-huo-dong"></a>

每年大学堂都会在万圣节把Hall装饰成鬼屋供港大学生来游玩，如果你住在Hall可以刚好尽地主之谊。Hall内其他活动也很多，包括辩论、出游等，还会举办和薄扶林社区文化相关的 Pokfulam Union Activities。Hall 内各种 team 也较为齐全，随着新 re-admission 制度的实施，若想成功留宿，内地生最好参加至少一个hall team以及积极参加其他hall内活动。同时，高桌晚宴通常会在 Hall 内的 dining hall 进行，一般都要求穿绿袍和佩戴 UHall Tie（Hall里有卖）。Hall中内地生每届十个左右。

### Readmission <a href="#readmission" id="readmission"></a>

不论是本地生或非本地生，都需要在每年四月通过 HKU Portal提交续住申请。申请人需要具备 CGPA>=2.0 的学业成绩。

申请后会有面试（一般是学生会的干部以及舍监进行面试），然后等约两周后会收到Readmission 的结果。Readmission 采取 Merit Score 评分系统，计算方式如下：

| Item                                                        | Weight                                        |   |     |
| ----------------------------------------------------------- | --------------------------------------------- | - | --- |
| Academic Performance                                        | 50%                                           |   |     |
| Participation                                               | 50%                                           |   |     |
|                                                             | Participation in hall team and interest group |   | 30% |
| Participation in committee, sub-committee and working group | 10%                                           |   |     |
| Participation in hall event                                 | 10%                                           |   |     |

### 前往大学堂 <a href="#qian-wang-da-xue-tang" id="qian-wang-da-xue-tang"></a>

巴士至薄扶林明德村和薄扶林水塘道都可，明德村通向大学堂正门，水塘道站通向小路。因为小路比较近，所以宿生一般会选择在水塘道站下车。
