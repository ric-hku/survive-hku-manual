# 何东夫人纪念堂入住指南

### A. 基本信息（位置&性别&室友） <a href="#a-ji-ben-xin-xi-wei-zhi-xing-bie-shi-you" id="a-ji-ben-xin-xi-wei-zhi-xing-bie-shi-you"></a>

1. 位置:何东夫人纪念堂位于赛马会第一学生舍堂村，紧邻港铁香港大学站C1出口。
2. 性别构成:女
3. 室友背景：

注：从2023年起，港大校委会决定为了促进交流融合，在新学年将内地新生安排与本地生或者国际学生做室友。宿舍办公室将为入住双人房的新入住宿生配对室友，务求本地生要和非本地生，包括海外和内地生住同一间房。留宿第二年起可以自行选择室友或者根据各Hall内部安排确定新室友（但一般情况下只能满足大部分同学的诉求，不能保证百分之百满足）。新生最初默认分到双人间，单人间需要向 Hall Office 写邮件提出申请（如果因为身体原因需要单人间，则必须提供医生开具的证明。任何时候均可提出申请，需于 waitinglist 等候）。学期中如果有空床位也可以申请调换，Hall Office 会酌情考虑。

### B. 居住概况（房间&床&家具） <a href="#b-ju-zhu-gai-kuang-fang-jian-chuang-jia-ju" id="b-ju-zhu-gai-kuang-fang-jian-chuang-jia-ju"></a>

1. 房间类型：

第一年如无特殊要求的一般是双人间，第二年及之后可以申请单人间。

2. 房间尺寸：大约 12 平方米（双人间）
3. 卫生间＆浴室：每层有 5 个卫生间和 4 个淋浴室，每个单元以隔断分开。
4. 床的尺寸：200 x 90 cm。提供床垫（雅兰席梦思床垫是何东三宝之一）和小薄垫（每层楼情况不同），自己需要准备的床具有床单，枕头，被子，如果不方便从家里带的话，可以在西宝城里的日本城、惠康之类的商店购买。

### C. 衣物相关洗衣机&衣柜 <a href="#c-yi-wu-xiang-guan-xi-yi-ji-yi-gui" id="c-yi-wu-xiang-guan-xi-yi-ji-yi-gui"></a>

1. 洗衣＆烘干：

Hall 内的洗衣房位于顶楼，共有 5 台洗衣机和 4 台烘干机，机器全部只接受八达通付款，洗衣一次 4 港币，烘干每五分钟 1 港币。洗衣房的旁边是晾衣服的地方。

### D. 饮食概况（餐厅\&Pantry&售货机） <a href="#d-yin-shi-gai-kuang-can-ting-pantry-shou-huo-ji" id="d-yin-shi-gai-kuang-can-ting-pantry-shou-huo-ji"></a>

### 1. 附近餐厅： <a href="#id-1-fu-jin-can-ting" id="id-1-fu-jin-can-ting"></a>

Hall附近没有餐厅，同学们可以选择到校园就餐，或者到周边觅食。可以参考公众号“港大RIC锐克” 推送《如何优雅地快乐干饭》（点击查看）

### 2. Pantry： <a href="#id-2-pantry" id="id-2-pantry"></a>

Hall 里每层都有 pantry, 并且有必要厨具（如电磁炉、烤箱、微波炉、锅等）、调料（如基本的油，盐，酱油等调料）以及冰箱（冰箱每个房间有一小格储存空间，另有专门冷藏冷冻的共用隔间）。在 hall 做饭需要自己准备基本餐具（如碗筷等），特殊的餐具或是厨具则视个人情况而定。做饭买原材料最方便的超市在西宝城里的惠康。

### 3. 自动售货机 ： <a href="#id-3-zi-dong-shou-huo-ji" id="id-3-zi-dong-shou-huo-ji"></a>

Hall 内有贩卖机，三台位于一楼（饮品+零食），一台位于十九楼（饮品）。

### E. 学习环境（书桌&自习室） <a href="#e-xue-xi-huan-jing-shu-zhuo-zi-xi-shi" id="e-xue-xi-huan-jing-shu-zhuo-zi-xi-shi"></a>

### 1. 书桌: <a href="#id-1-shu-zhuo" id="id-1-shu-zhuo"></a>

书桌为常规大小（约 1.1 米＊0.6 米左右），每个桌子上方有灯管和书架。

### 2. 打印＆复印: <a href="#id-2-da-yin-fu-yin" id="id-2-da-yin-fu-yin"></a>

Hall 内有打印机（只能黑白打印），位于一楼，使用方法与学校打印机一致。

### 3. 自习室 <a href="#id-3-zi-xi-shi" id="id-3-zi-xi-shi"></a>

一楼有一间小的function room 在平时可以随意出入当做自习室使用，配备有桌椅。通常在复习周和考试周期间hall会将大多数function rooms开设为自习室。

### F. 活动＆相关设施（活动室＆活动队） <a href="#f-huo-dong-xiang-guan-she-shi-huo-dong-shi-huo-dong-dui" id="f-huo-dong-xiang-guan-she-shi-huo-dong-shi-huo-dong-dui"></a>

### 1. 活动室： <a href="#id-1-huo-dong-shi" id="id-1-huo-dong-shi"></a>

Hall 内一楼有多间 function room，包括一间有钢琴的房间。

### 2. 体育运动 <a href="#id-2-ti-yu-yun-dong" id="id-2-ti-yu-yun-dong"></a>

何东拥有丰富的体育队可以加入，如羽毛球、乒乓球、排球、垒球、曲棍球和游泳队等。附近的主要运动场所是校内的健身房，和 Stanley Ho 的室外场地。但部分球类运动如乒乓球则在一村内的何添堂进行。

### 3. Hall 内其他活动 <a href="#id-3hall-nei-qi-ta-huo-dong" id="id-3hall-nei-qi-ta-huo-dong"></a>

Hall 内有丰富的活动如 Gong Fight（与同住在一村男生宿舍利玛窦的男生进行的一场打水仗游戏）， Ho Tung festival（举行为期三天的以楼层为单位的竞赛，包括体育，文化，益智等诸多方面的小比赛）,Welcome Party, Farewell Party 等等。（每年活动情况有差异）

### G. Readmission（考核标准） <a href="#greadmission-kao-he-biao-zhun" id="greadmission-kao-he-biao-zhun"></a>

不论是本地生或非本地生，都需要在每年四月通过 HKU Portal提交续住申请。从2023-24年起，申请人需要具备CGPA>=2.0的学业成绩。

每年政策波动较大，一般是GPA + 为 hall 做出contribution（包括：必须参加的活动如high table dinner，和选择参加的各种 team，以及代表 hall 参加 inter-hall 比赛等）。注：自2024年起，学校提出“P-1”政策，具体详情可以参考公众号“港大RIC锐克” 推送《2025 Readmission 申请及变动》（点击查看）

H. 前往何东（机场至 hall 线路）

### 1. 香港机场出发 <a href="#id-1-xiang-gang-ji-chang-chu-fa" id="id-1-xiang-gang-ji-chang-chu-fa"></a>

a）在机场乘坐机场快线到达香港站，在地铁站内步行至中环站换乘西港岛线

（坚尼地城方向）经过 3 站到达香港大学站，从 C1 出口出，沿着薄扶林道向上走30 米左右到达赛马会第一舍堂村；全程约花费港币 110 元；（推荐线路）。

b）在机场地面运输中心乘坐城巴 A10（鸭脷洲总站方向），经过 6 站在西宝城站下车， 经登山电梯上山后沿薄扶林道上行 20 米左右到达赛马会第一舍堂村；全程花费约港币 50 元；（此线路较复杂，需提前做好规划）。

c) 搭乘的士前往，花费约港币 300－400 元。

### 2.深圳机场 <a href="#id-2-shen-zhen-ji-chang" id="id-2-shen-zhen-ji-chang"></a>

a) 在机场地面运输中心乘坐中港通巴士（票价¥130，经过深圳湾入关，有工作人员指引）到达上环下车（一般停靠在港澳码头），乘地铁西港岛线（坚尼地城方向）经过 2 站到达香港大学站，C1 口出沿薄扶林道上行 30 米到达；或在港澳码头搭乘出租车，花费约 35－40 元。

### I. 从何东出发到HKU（hall 至学校线路） <a href="#i-cong-he-dong-chu-fa-dao-hkuhall-zhi-xue-xiao-xian-lu" id="i-cong-he-dong-chu-fa-dao-hkuhall-zhi-xue-xiao-xian-lu"></a>

出 hall 直接沿薄扶林道步行，经过地铁站（C 出口）乘电梯进入百周年校区；

或过马路沿薄扶林道至地铁站（A 出口），搭乘旁边电梯到达黄克竞楼。通常步行到达校园时间在 5-10 分钟。
