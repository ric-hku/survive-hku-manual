# 施德堂入住指南

### A. 基本信息（位置&性别&室友）

### 1. 位置 <a href="#id-1-wei-zhi" id="id-1-wei-zhi"></a>

施德堂位于赛马会第一学生舍堂村，紧邻港铁香港大学站。

![](https://cdn-mineru.openxlab.org.cn/result/2026-06-22/da8f23ff-123c-4ee0-8620-507e6ac82e25/4902e7393a36acbdeb279a42cc6f0bc160f3644f2cb3e3d8fd94e9eb20065c05.jpg)

### 2. 性别构成 <a href="#id-2-xing-bie-gou-cheng" id="id-2-xing-bie-gou-cheng"></a>

男女隔层混住，每两层（即一男生层一女生层）为一个Unit，平时会有许多以Unit为单位进行的活动。

### 3. 舍友背景 <a href="#id-3-she-you-bei-jing" id="id-3-she-you-bei-jing"></a>

第一年一般只能住双人间，抽签决定房间和室友，如第二年Readmission成功则可选择室友，但一般楼层不会变动。

### B. 居住概况房间&床&家具 <a href="#b-ju-zhu-gai-kuang-fang-jian-chuang-jia-ju" id="b-ju-zhu-gai-kuang-fang-jian-chuang-jia-ju"></a>

### 1. 房间类型 <a href="#id-1-fang-jian-lei-xing" id="id-1-fang-jian-lei-xing"></a>

第一年一般住双人间，每层有两个单人间，通常第一间住的是Postgraduate或者是PHD ，是本层的Tutor，另外一间会给Undergraduate住，可以在期末时申请，申请人数大于空位数量则抽签决定人选，一次可以住一年（一般情况下Undergraduate的学生最多住一年单人间）。

### 2. 房间尺寸 <a href="#id-2-fang-jian-chi-cun" id="id-2-fang-jian-chi-cun"></a>

双人间大约15平方米

### 3. 卫生间/浴室 <a href="#id-3-wei-sheng-jian-yu-shi" id="id-3-wei-sheng-jian-yu-shi"></a>

每层有 2 个卫生间和有 4 个隔间的浴室。浴室以隔断分开，提供淋浴。

### 4. 床 <a href="#id-4-chuang" id="id-4-chuang"></a>

床的尺寸：210cm\*90cm。提供床垫，床垫大概高10cm，自己需要准备床单、枕头、被子、被套，不方便从家里带的话可以在Hall附近购买，比如去西宝城、港大地铁站B出 口附近的日本城、坚尼地城的实惠、铜锣湾的宜家等地方购买。

### 5. 家具 <a href="#id-5-jia-ju" id="id-5-jia-ju"></a>

房间内每人各有一张床，一个书桌，一个衣柜以及一个床头柜（详情在下文中介绍）。

### C. 衣物相关洗衣机&衣柜 <a href="#c-yi-wu-xiang-guan-xi-yi-ji-yi-gui" id="c-yi-wu-xiang-guan-xi-yi-ji-yi-gui"></a>

### 1. 洗衣&烘干 <a href="#id-1-xi-yi-hong-gan" id="id-1-xi-yi-hong-gan"></a>

Hall内顶层有洗衣房，有八台洗衣机、四台烘干机和晾衣服的地方，付款方式是八达 通。洗衣服通常一次5.2HKD，烘干机每1.3HKD可运行5分钟，一般需烘干40分钟左右 （具体视衣服量而定），因此洗烘衣服通常为15.6HKD。Starr除了室内有晾衣服的地方， 24楼尽头有带顶天台，可以晾衣服，但要注意天台风大，衣架要选不易从晾衣杆上脱 落的，并且要注意门上的标识，天台有的时候是不开放的。

### 2. 衣物储存 <a href="#id-2-yi-wu-chu-cun" id="id-2-yi-wu-chu-cun"></a>

房间内有一个大衣柜（接近墙高，约2-2.5米），里面有隔板分成一个大衣橱（可以挂大件 衣物和存放被子）和四个柜子（能塞下一床薄被子的大小）；还有六个抽屉式衣柜可以存放衣物和日用品，衣柜顶可放置大概两个24寸行李箱；床边有一个床头柜，桌子下方也有一个柜子，床下有两个柜子（可以用来放鞋子）；可以准备若干衣架用来挂放大件 衣服或晾晒衣物（一般挂在天花板的灯上）；把床垫移开后，可以露出床自带的非常大 的储物格子，可以把非本季的衣服放在其中，但是要注意防潮。

### D. 饮食概况：餐厅&厨房&售货机 <a href="#d-yin-shi-gai-kuang-can-ting-chu-fang-shou-huo-ji" id="d-yin-shi-gai-kuang-can-ting-chu-fang-shou-huo-ji"></a>

### 1. 附近餐厅 <a href="#id-1-fu-jin-can-ting" id="id-1-fu-jin-can-ting"></a>

最近的校外餐厅位于西宝城内，可以通过登山扶梯或者经过港大地铁站抵达，由于距 离学校非常近，所以也可以考虑在校内的餐厅进行用餐，步行到校内的东南亚、Alfafa 、Bijas、Super Sandwich一般只需要五分钟，总体来说非常便捷。

### 2. 厨房 (Pantry) <a href="#id-2-chu-fang-pantry" id="id-2-chu-fang-pantry"></a>

每一层有一个Pantry，一般都有电磁炉和锅碗瓢盆，每个楼层也会根据自己情况购买调 料和其他材料（费用一般集体收取Unit费，不过也有很多楼层不收）；每层有一个或两个 单开门冰箱（冰箱上冷藏下冷冻，不过通常大家都会放很多东西进去，所以自己放东西 的时候注意写上房间和姓名）；餐具一般可以准备一副碗筷（大家可能会一起做饭或是 打边炉），如果有做饭爱好的可以自行买锅或者其他材料，餐具和食材可以在山下西宝 城里的惠康超市购买，日本城也可以买到餐具和厨具。

### 3. 自动售货机 <a href="#id-3-zi-dong-shou-huo-ji" id="id-3-zi-dong-shou-huo-ji"></a>

在 Hall 内 G 层有三台贩卖机，两台卖饮料，另外一台卖零食，肥宅水价格比超市还便宜。

### E. 学习环境书桌&自习室 <a href="#e-xue-xi-huan-jing-shu-zhuo-zi-xi-shi" id="e-xue-xi-huan-jing-shu-zhuo-zi-xi-shi"></a>

### 1. 房间内书桌 <a href="#id-1-fang-jian-nei-shu-zhuo" id="id-1-fang-jian-nei-shu-zhuo"></a>

书桌为常规大小（约110cm\*60cm），每个桌子上方有一悬挂灯管，书桌上方有多用格6个，可用于存放书本和杂物，书桌靠枪的地方是软木板，上面会有图钉，可以把一些便利贴、备忘录用图钉钉到墙上

### 2. 自习室 <a href="#id-2-zi-xi-shi" id="id-2-zi-xi-shi"></a>

Hall 会在 Revision Week 将 1/F 开放为 Study Area，平时 1/F 也有 Multi-function Room，一般 供社团活动预订使用。每层的Pantry也可以用来学习。

### 3. 打印&复印 <a href="#id-3-da-yin-fu-yin" id="id-3-da-yin-fu-yin"></a>

Hall内有打印复印设备，位于一楼(需要下载插件才能使用)，可以通过U盘传输要打印 的资料；同时可以在G层的Office打印复印发送传真（收取一定费用）。

### F. 活动＆相关设施活动室＆活动队 <a href="#f-huo-dong-xiang-guan-she-shi-huo-dong-shi-huo-dong-dui" id="f-huo-dong-xiang-guan-she-shi-huo-dong-shi-huo-dong-dui"></a>

### 1. 活动室 <a href="#id-1-huo-dong-shi" id="id-1-huo-dong-shi"></a>

Hall 的 Multi-function Room 有一架钢琴，也有 Band Room 供 Hall 乐队排练。

### 2. 社团活动 <a href="#id-2-she-tuan-huo-dong" id="id-2-she-tuan-huo-dong"></a>

Hall Team基本涵盖所有Inter-hall项目，包括传统项目如游泳、篮球、足球、排球、乒乓球、羽毛球，新式球类项目如草地曲棍球、垒球、长曲棍球，文艺项目包括合唱、戏 剧、粤语辩论、乐队、厨艺俱乐部、手工、桥牌、国际象棋等。Starr的体育项目和合唱团都非常强，经常得奖，合唱团偶尔能接到外出演出的邀请。厨艺和手工俱乐部的内地生比例很高。

### 3. Hall 内其他活动 <a href="#id-3hall-nei-qi-ta-huo-dong" id="id-3hall-nei-qi-ta-huo-dong"></a>

Hall 内每个学期会有 2-3 次 High Table Dinner。其他活动包括： Starr Festival ；Inter-unitCompetition（Unit 之间的体育比赛）； 期末 Unit 劲过劈猪挥春； Starr Lung SingingContest...（均非强制性参与，全凭兴趣）。

### G. Readmission 考核标准 <a href="#greadmission-kao-he-biao-zhun" id="greadmission-kao-he-biao-zhun"></a>

总体对于内地生来说不难，目前的考核标准已经把GPA纳入了考虑。不过具体难度根据楼层和Unit的不同可能会有所区别。不论如 何，平时尽量跟楼友保持较好的关系（见面打招呼保持礼貌）。 如果有兴趣可以参加 Hall里的Team或Interest Group。面试时候说到自己对于Hall有所贡献，对于住Hall的想 法，未来在Hall里的打算，不可表现出只是把Hall当作一个旅馆的感觉，在校内或者校 外的一些贡献活动也可以说，需要记住你所在Unit的Tutor，你的层主，Warden 的名字。 Starr Hall 面试一般不考核 Hall Song。

### H. 前往施德 <a href="#h-qian-wang-shi-de" id="h-qian-wang-shi-de"></a>

### 1. 香港机场至hall线路 <a href="#id-1-xiang-gang-ji-chang-zhi-hall-xian-lu" id="id-1-xiang-gang-ji-chang-zhi-hall-xian-lu"></a>

a)在机场乘坐机场快线到达香港站，在地铁站内步行至中环站换乘港岛线（坚尼地城 方向）经过3站到达香港大学站，从C1出口出，沿着薄扶林道向上走30米左右到达赛马 会第一舍堂村；全程花费港币约110元；

b)在机场地面运输中心乘坐城巴A10（鸭脷洲总站方向），经过6站在西宝城站下车，经登山电梯上山后沿薄扶林道上行20米左右到达赛马会第一舍堂村；全程花费港币约50元；

c)搭乘的士前往，花费约300－400HKD。

### 2. 深圳机场至hall路线 <a href="#id-2-shen-zhen-ji-chang-zhi-hall-lu-xian" id="id-2-shen-zhen-ji-chang-zhi-hall-lu-xian"></a>

在机场地面运输中心乘坐中港通巴士（票价130RMB，经过深圳湾入关，有工作人员指引）到达上环下车（一般停靠在港澳码头），乘地铁港岛线（坚尼地城方向）经过2站到达香港大学站，C1口出沿薄扶林道上行30米到达；或在港澳码头搭乘出租车，花费约 3－40HKD。

### I. 从施德出发（Hall至学校线路） <a href="#ii-cong-shi-de-chu-fa-hall-zhi-xue-xiao-xian-lu" id="ii-cong-shi-de-chu-fa-hall-zhi-xue-xiao-xian-lu"></a>

出Hall直接沿薄扶林道步行，经过地铁站（C出口站）乘电梯进入百周年校区；或从地铁站里面穿行至A出口乘电梯直接进入校园（SU平台）；或过马路直接走到A出口搭电梯进入校园，到达A出口若继续往前走则是Main Building；或直接步行通过劲过桥进入百 周年校园地下；通常步行到达校园一端的时间是10分钟，更远的教室需要预留更长的时间。
