# 马礼逊堂入住指南

### A 基本信息&位置&性别&室友 <a href="#a-ji-ben-xin-xi-wei-zhi-xing-bie-shi-you" id="a-ji-ben-xin-xi-wei-zhi-xing-bie-shi-you"></a>

### 1. 位置 <a href="#id-1-wei-zhi" id="id-1-wei-zhi"></a>

香港大学马礼逊堂位于赛马会第二舍堂村，薄扶林道 109 号，Pokfulam Road 109，到主校区 约十五分钟步行距离。

![image](https://cdn-mineru.openxlab.org.cn/result/2026-06-22/f256582a-6943-4913-a409-1beda8c177d0/5464db9604108cd14ca05f3493e38acc9997c6ee2084ce62398f233df0b54c68.jpg)



### 2. 性别构成 <a href="#id-2-xing-bie-gou-cheng" id="id-2-xing-bie-gou-cheng"></a>

马礼逊是几个既有本科生又有研究生居住的 Hall 之一，本科生原本为纯男层，从 2017 年开始加入女生，研究生男女比例1：1，男女分层。2023年研究生层的数量有减少，开始有女本科生层。

### 3. 舍友背景 <a href="#id-3-she-you-bei-jing" id="id-3-she-you-bei-jing"></a>

由于香港大学有关促进不同背景学生交流的政策，对于新入住学生，宿舍办公室会尽可能将本地和非本地学生配对。

### B 居住概况 <a href="#b-ju-zhu-gai-kuang" id="b-ju-zhu-gai-kuang"></a>

### 1. 房间类型 <a href="#id-1-fang-jian-lei-xing" id="id-1-fang-jian-lei-xing"></a>

舍堂以双人间为主，每层至少有一个单人间，但基本上属于Floor Representative。

### 2. 床 <a href="#id-2-chuang" id="id-2-chuang"></a>

房间提供床垫，需自带床单，枕头，被子等（可在来到香港后购买，舍堂内不提供购买选项），床垫尺寸约为0.9m\*2.1m。房间内有空调，需要在Floor Pantry八达通充值机充值后使用。

### C 衣物相关 <a href="#c-yi-wu-xiang-guan" id="c-yi-wu-xiang-guan"></a>

### 1. 洗衣&烘干 <a href="#id-1-xi-yi-hong-gan" id="id-1-xi-yi-hong-gan"></a>

MHall 十五层顶楼设有八达通洗衣机和烘干机，洗衣一次 4 元，干衣一次 2 元（10 分钟）。 同时也可以使用位于顶层的晾衣房。

### 2. 衣物储存 <a href="#id-2-yi-wu-chu-cun" id="id-2-yi-wu-chu-cun"></a>

房间内设有衣橱，床下柜，床头柜，书桌抽屉等储物空间，不提供衣架和鞋柜，建议同学来 港时视需求准备，或直接在香港购买。

### D 饮食概况 <a href="#d-yin-shi-gai-kuang" id="d-yin-shi-gai-kuang"></a>

### 1. 日常就餐 <a href="#id-1-ri-chang-jiu-can" id="id-1-ri-chang-jiu-can"></a>

二村没有餐厅，如需就餐可以有以下四个选择：

自己制作：每层楼的Pantry提供电磁炉、微波炉、饮水机和冰箱，可能需要自备锅具和餐具。原材料可在西宝城惠康或附近石塘咀/士美菲路熟食中心购买。

● 步行下坡前往学校主校区附近。

● 前往玛丽医院：步行至蒲飞路巴士站搭乘巴士前往玛丽医院餐厅。

● 步行下坡前往坚尼地城，路程约10-15分钟。

### 2. 自动售货机 <a href="#id-2-zi-dong-shou-huo-ji" id="id-2-zi-dong-shou-huo-ji"></a>

G 层 lobby 是公共活动空间，其中有两个自动贩售机分别售卖零食和饮料。

### E 学习环境 <a href="#e-xue-xi-huan-jing" id="e-xue-xi-huan-jing"></a>

### 1. 书桌与自习室 <a href="#id-1-shu-zhuo-yu-zi-xi-shi" id="id-1-shu-zhuo-yu-zi-xi-shi"></a>

书桌上有读书灯（灯管），有三层共六格书架。

### 2. 打印&复印 <a href="#id-2-da-yin-fu-yin" id="id-2-da-yin-fu-yin"></a>

Lobby内有打印复印一体机，打印只支持打印U盘中的pdf文件。

### F 活动&相关设施 <a href="#f-huo-dong-xiang-guan-she-shi" id="f-huo-dong-xiang-guan-she-shi"></a>

### 1. 活动室 <a href="#id-1-huo-dong-shi" id="id-1-huo-dong-shi"></a>

Lobby 的活动室内有钢琴供 Choir 练习和平时娱乐；部分Club 会在Lobby定期举行活动。

### 2. 体育运动 <a href="#id-2-ti-yu-yun-dong" id="id-2-ti-yu-yun-dong"></a>

较近的选择：隔壁舍堂孙志新堂楼下有多功能活动室，有健身器材（可以walk-in）和活动室（例如舞蹈房，需预约）供大家使用。

较远的选择：可以前往Stanley Ho体育中心或者前往学校健身房。

### 3. Hall 其他活动 <a href="#id-3hall-qi-ta-huo-dong" id="id-3hall-qi-ta-huo-dong"></a>

Hall festival，English orientation，Welcoming party，“劲过”活动等。High Table Dinner 高桌晚宴需学生强制参加，每学期的次数不固定但至少有一次。

Hall里有各种运动队 (篮球，棒球 etc.) 和活动俱乐部 (桌游，电影，摄影 etc. ) 大家可以按需参加。这些运动队和俱乐部招新时会在电梯里张贴海报，大家可以自行报名。由于MHall内地生比例相对较高，因此也有许多内地生社团，不会粤语的小伙伴无需担心可以和大家愉快玩耍。

### G Readmission <a href="#g-readmission" id="g-readmission"></a>

不论是本地生或非本地生，都需要在每年四月通过 HKU Portal提交续住申請。从2023-24年起，申請人需要具备CGPA>=2.0的学业成绩。

Readmission评分分为楼层评分，hall内评分，Hall song考核和面试四部分。楼层评分是通过每层的堂友填写一张表，给自己的楼友以及楼长打分。由于不同层可能规定稍稍不同，有的层楼会要求 nonlocal参加，有的层不会。如果 nonlocal也被要求参加楼会，请尽量参加。第二是 Hall 内评分。第二学期末 Hall 会提供一张表格，里面会有本学期所有的Team/Club以及相关的一些活动(包括一些Tutor Forum)等，让堂友勾选自己所参加的活动，以及做的贡献。Team Captain/Club Leander 会对你今年在 team 里的表现进行评分。Hallsong考核是强制性的，需要记住歌词，穿着指定服装，旋律基本准确，态度端正即可。面试会有 Hall的Tutor 针对你提交的Readmission表格内容进行问询，如实回答即可。能稳定参加 hall team 的活动或者 Inter-Hall Competition，参加 Hall 的活动，High table 不缺席，以开放的心态试着和楼友交往，并且学会Hall song，通过 Readmission的把握会比较大。

### H 前往马礼逊 <a href="#h-qian-wang-ma-li-xun" id="h-qian-wang-ma-li-xun"></a>

建议最优线路：

从香港机场：乘机场快线到香港站，转乘港岛线到香港大学站 C1 出口步行即可。

从深圳机场：乘过境巴士到上环地铁站后转乘港岛线，到香港大学站 C1 出口步行即可。

由于从C1出口步行至二村为上坡路段，如携带行李不便的同学建议打车前往。

注意，由于蒲飞路校区建设工程，二村出入口有所更改，Google Form上显示的出入口无法使用（如下图），需要继续沿薄扶林道往上走一段路通过回转坡道或行人电梯进入。

### 重要告示 <a href="#zhong-yao-gao-shi" id="zhong-yao-gao-shi"></a>

因應工程需要，由薄扶林道通往賽馬會第二舍堂村(馬禮遜堂、孫志新堂、李兆基堂)之車輛及行人通道已經關閉並納入地盤範圍，改為經由新建停車場行車坡道大樓連接薄扶林道。

行人請按照指示使用樓梯及升降機通往薄扶林道。另一條專用通道亦將於繁忙時間及夜間(上午8時至上午8時半；晚上7時至翌日上午7時)開放予行人使用。

通道出入口處將安排交通督導員值勤，確保交通安全。

### I 从马礼逊出发 <a href="#i-cong-ma-li-xun-chu-fa" id="i-cong-ma-li-xun-chu-fa"></a>

从 hall 到学校：

一般步行即可，步行时长约10-15分钟；赶时间的同学可以搭乘校巴，或者富林苑巴士站搭乘巴士。

### J 一些个人居住体验 <a href="#j-yi-xie-ge-ren-ju-zhu-ti-yan" id="j-yi-xie-ge-ren-ju-zhu-ti-yan"></a>

由于蒲飞路校园建设施工，工作日白天和周六可能会产生噪音影响居住体验。
