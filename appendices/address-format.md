# 内地、香港地址格式参考

## 一、内地地址

如果是投递、邮寄等用途，直接用中文即可。

如果用于填表等用途，需要用拉丁字母拼写，则可以用拼音或是英文。此时，需要从小到大书写。

### 常用英文及缩写

室 = Room / Rm.　层 = Floor / F　单元 = Unit　幢 / 栋 = Building / Bldg.\
小区 / 社区 = Community　花园 = Garden　公寓 = Apartment / Apt.\
组 = Group　号 = Number / No.　巷 = Lane / Ln.　弄 = Alley / Aly.\
路 = Road / Rd.　街 / 大街 = Street / St.　大道 = Avenue / Ave.\
村 = Village　街道 = Subdistrict　镇 = Town　乡 = Township\
区 = District / Dist.　县 = County　市 = City　省 = Province / Prov.

### 示例

中国北京市海淀区知春路 12 号太月园 3 号楼 10 楼 1001 室（邮编：100088）

Rm. 1001, 10/F, Bldg. 3, Taiyueyuan\
No. 12 Zhichun Rd., Haidian District\
Beijing 100088, P. R. China

中国广东省深圳市罗湖区南湖街道建设路 1002 号 1 号楼 501 室（邮编：518005）

Rm. 501, Bldg. 1, No. 1002 Jianshe Rd.\
Nanhu Subdist., Luohu Dist., Shenzhen\
Guangdong 518005, P. R. China

中国浙江省杭州市淳安县安阳乡范家村 1 组（邮编：311708）

Group 1, Fanjia Village, Anyang Town\
Chun'an County, Hangzhou City\
Zhejiang Province 311708, P. R. China

中国新疆维吾尔自治区乌鲁木齐市天山区胜利路街道延安路 950 号（邮编：830049）

No. 950 Yan'an Rd., Shenglilu Subdistrict\
Tianshan District, Urumqi City\
Xinjiang 830049, P. R. China

{% hint style="info" %}
**仅供参考。**

如果有长度、字数等要求，可以考虑：

* 将一部分内容调整到上 / 下一行；
* 适当使用缩写；
* 删去一部分不影响地址识别的内容，如邮编、国名、街道、Province / City / District 等词。

保持从小到大顺序和地址可识别性即可。
{% endhint %}

## 二、香港地址

香港的地址可以用**中文或英文**书写。邮寄时，两种文字的地址都能够使用。

[香港邮政 - 查找邮寄地址格式](https://webapp.hongkongpost.hk/correct_addressing2/index.html?lang=sc)

### 一般格式

中文：

香港、九龙或新界\
乡村、市镇或地区名称\
街道名称及门牌号数\
建筑物名称、楼层、单位 / 室

英文：

Flat / Room and Floor Numbers\
Name of Building\
Building Number and Name of Street\
NAME OF VILLAGE, TOWN or DISTRICT\
HONG KONG, KOWLOON or NEW TERRITORIES

### 示例

香港\
灣仔\
堅尼地道 105 號\
雅佳大廈 12 樓 25 室

Flat 25, 12/F\
Acacia Building\
105 Kennedy Road\
WAN CHAI\
HONG KONG

{% hint style="info" %}
注：现时，**香港没有采用邮政编码系统**。市民如须在网站填写香港的邮政编码，可考虑**留空该栏**或尝试其他人士惯常使用的 **“000”**、**“0000”**、**“000000”** 或 **“HKG”** 等方法。
{% endhint %}
