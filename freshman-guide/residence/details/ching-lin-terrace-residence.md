# 青莲台学生宿舍入住指南

写在前面：青莲台并不属于港大传统意义上的“Residential hall”，更多作为港大PhD学生短期住宿之用。由于港大从 2017 年开始扩招，导致传统舍堂的宿位不足，因此一部分申请hall的本科同学会被分到青莲台住宿，但分配的具体标准目前尚不清楚。

CEDARS 官方青莲台宿舍介绍网站：[https://housing.cedars.hku.hk/university-accommodation/residence-options/ching-lin-terrace-residence](https://housing.cedars.hku.hk/university-accommodation/residence-options/ching-lin-terrace-residence)

### A. 基本信息 <a href="#a-ji-ben-xin-xi" id="a-ji-ben-xin-xi"></a>

1. 位置及路线（CEDARS 官网有详细路线及照片）

青莲台位于一村和二村中间，处在薄扶林道和坚尼地城的半山腰上。到达青莲台有两种方式，一是由坚城地铁站B口出之后右转直走到尽头，沿升降梯和手扶梯上到半山腰，再爬一段楼梯即可到达。另一种方式是从港大C口出沿着薄扶林道直走，在走过一村约三分钟之后会看到一个有着“鲁班先师庙”的指示牌，沿该路口下三段楼梯即可到达青莲台平台。

由于进出青莲台需要经常爬山且没有替代路线，笔者个人不建议需要经常携带大件物品的同学们选择这里，会比较麻烦。

### 2. 性别构成 <a href="#id-2-xing-bie-gou-cheng" id="id-2-xing-bie-gou-cheng"></a>

男女混住，但同一个套间里室友的性别会相同。通常而言5层及以上是女生居住，5层以下是男生居住。

### 3. 舍友背景 <a href="#id-3-she-you-bei-jing" id="id-3-she-you-bei-jing"></a>

内地生和国际生都有。由于其主要用途是给研究生、博士生或者交换学生住，所以舍友较为多元化，且内地新生占比较小。

### B. 居住概况 <a href="#b-ju-zhu-gai-kuang" id="b-ju-zhu-gai-kuang"></a>

1. 房间类型（相关图片可参考 CEDARS 官网）



每层楼有四个套间，每个套间里有一个客厅和厨房，再有若干个单人间或双人间，通常是三个单人间加上一个双人间。单人间分为上床下桌和一边床一边桌两种。

### 2. 其他设施 <a href="#id-2-qi-ta-she-shi" id="id-2-qi-ta-she-shi"></a>

青莲台的设施较为老旧，客厅、厨房比较宽敞但房间内空间很小，每个套间有两个共用卫生间，其中一个可用于淋浴。客厅配有桌椅、沙发、电视、微波炉、冰箱。

### 3. 衣物相关 <a href="#id-3-yi-wu-xiang-guan" id="id-3-yi-wu-xiang-guan"></a>

青莲台配有两台洗衣机和两台烘干机，提供给整栋楼的学生使用，通过刷八达通付费使用，洗一次衣服需要4HKD，烘干衣服的花费则视烘干时间而定（每5分钟1HKD）。洗衣机和烘干机马力非常足，洗多件衣服甚至是被单等都完全无压力。 在洗衣高峰期（如周末的晚上）需要排队，洗衣机偶尔会坏。

### 4. 饮食概况 <a href="#id-4-yin-shi-gai-kuang" id="id-4-yin-shi-gai-kuang"></a>

青莲台本身并没有自带餐厅或零食售卖机，但可以在套间的公用厨房做饭。青莲台下楼就是生活气息满满的坚尼地城，各种美食应有尽有。

### 5. 其他设施及活动 <a href="#id-5-qi-ta-she-shi-ji-huo-dong" id="id-5-qi-ta-she-shi-ji-huo-dong"></a>

青莲台的 G 层有一个大厅，平时可供 residents 自习到晚上十点。由于青莲台和蒲飞路一样不属于正式的 Residential hall，所以并没有 hall 会有的 High Table Dinner 或者 Hall Team等活动，平时生活非常清静，可以说是养老圣地。但同时青莲台也是一个非常富有人情味的地方，hall里的tutor逛街回来会把好吃的分给大家，逢年过节大家也会自发的在G层大厅组织活动如包饺子、写春联等。

### 6. 收费及补贴 <a href="#id-6-shou-fei-ji-bu-tie" id="id-6-shou-fei-ji-bu-tie"></a>

青莲台的宿舍根据房型、人数、房间大小、有无独立洗手间会分别收取不同的价格，具体可以移步查看 CEDARS 对于青莲台宿舍的介绍。最便宜的两人间价格在 4700HKD 左右，单人间价格在5000-6000HKD。

### C. Readmission 考核标准 <a href="#creadmission-kao-he-biao-zhun" id="creadmission-kao-he-biao-zhun"></a>

青莲台目前还不接受 Readmission，大一入住的新生只能住一年，在sem2结束之后就必须搬出（笔者试过延长了7 天住宿日期，但也只是延长而不能续住下一年，且延长这个操作并没有明文形式，所以需要自己跟青莲台的管理员协调）。所以在 sem2 快结束的时候就要想好是申请其他hall还是着手准备租房。

### D. 前往青莲台学生宿舍 <a href="#d-qian-wang-qing-lian-tai-xue-sheng-su-she" id="d-qian-wang-qing-lian-tai-xue-sheng-su-she"></a>

### 机场至hall线路 <a href="#ji-chang-zhi-hall-xian-lu" id="ji-chang-zhi-hall-xian-lu"></a>

### 1. 香港机场出发 <a href="#id-1-xiang-gang-ji-chang-chu-fa" id="id-1-xiang-gang-ji-chang-chu-fa"></a>

机场快线乘到香港站，步行至中环站。

港岛线乘到坚尼地城站，出 B口右转走至升降梯，沿升降梯上行后继续上坡，左侧可见青莲台标示，沿楼梯上行即可到达。

巴士：乘坐A10（机场地面运输中心上车，山市街下车）步行10-15分钟。

的士：行李多时首选，但的士只能开到升降梯下，仍需爬上行楼梯，花费大约 350 港币。

### 2. 深圳机场 <a href="#id-2-shen-zhen-ji-chang" id="id-2-shen-zhen-ji-chang"></a>

乘坐中港通巴士到终点上环下车

转乘港铁到坚尼地城站，出B口走5-10分钟。

### E. 青莲台出发前往学校 <a href="#e-qing-lian-tai-chu-fa-qian-wang-xue-xiao" id="e-qing-lian-tai-chu-fa-qian-wang-xue-xiao"></a>

可以上坡步行至学校C口，大约10-15分钟。也可以下坡去到坚尼地城地铁站，坐一个站到香港大学。
