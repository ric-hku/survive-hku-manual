# ID995A 表格填写指南

## 一、整体说明

填写方式：

* 使用 PDF 阅读器（Adobe Acrobat Reader、福昕阅读器、Chrome 的 PDF 查看器等）进行填写，打印出来后签名，再扫描上传；或者
* 打印出来后手动填写、签名、粘贴相片等，再扫描上传。

{% hint style="info" %}
**"in BLOCK letters"** 表示**清楚地、不连笔地用印刷体书写**。如果手写填表，可以用**全大写**书写，以方便识别。
{% endhint %}

填写说明：

* 使用 A4 白纸**单面打印第 1 - 4 页**。
* 请确保**条形码能够清楚显示**在每一页的底部。

{% hint style="info" %}
为保证能够完整打印整页所有内容，在打印时可以在 “调整页面大小” 等设置选择 **“适合”** 或 **“缩小过大的页面”** 等。
{% endhint %}

* **只需填妥第 1 - 4 页**（第 2 页中第 3 部分无须填写）。
* 根据需要在每个页面的右下角签名。（16 岁以下申请者需让家长签名。）

{% hint style="warning" %}
注意：**数字签名和键盘输入不能作为签名**。
{% endhint %}

* 根据第 2 页的指示附上一张白色背景的彩色、正面近照。（[相片规格](https://www.immd.gov.hk/hks/residents/immigration/traveldoc/photorequirements.html)）
* □ 处，选择符合情况的一项打勾（✔）。
* 项目如果带有 **“（如适用）”、“（如有）”**，表示**如果 “不适用” 或 “无”，则可以不填**。
* 带有 \* 的项目，**需将不适用项删去（用横线划去）**。

## 二、各部分详细说明

{% hint style="info" %}
**只需打印、填写 “甲部 Part A：申请来港就读 Application for Study in Hong Kong”（第 1 - 4 页）即可。**

“乙部 Part B：申请以收养人身份来港居留（如适用）Application for Residence as Dependants (if applicable)” 无需填写。
{% endhint %}

### 1. 个人资料 Personal Particulars

说明：

1. **姓名（中文）**：可以填写简体中文或繁体中文。
2. 请确保**中英文姓名资料**与**身份证**、**往来港澳通行证**上的相符。
3. **出生日期**：注意格式为 “日 - 月 - 年”（dd-mm-yyyy）。
4. **出生地点、原居地（适用于内地、澳门及台湾居民）、现时定居国家／地区**：填写省级行政区即可。

{% hint style="info" %}
陕西：SHAANXI；\
内蒙古：NEI MONGOL / INNER MONGOLIA；\
西藏：XIZANG / TIBET。
{% endhint %}

5. **旅行证件**：如有往来港澳通行证，可以填写：
   * 旅行证件类别：EXIT-ENTRY PERMIT / EEP（往来港澳通行证）；
   * 旅行证件号码、签发地点、签发日期、届满日期：按证件填写。
6. **联络电话号码**：注意加上区号；格式无要求，如 (86)、+86 等即可。
7. **在定居国家／地区的居留时间**：按实际情况填写即可（如未曾变动，可填入自己的年龄）。

### 2. 拟来港就读时间 Proposed Stay in Hong Kong for Study

说明：

2. **拟在港逗留时间**：按 Offer 上的 **Programme Duration** 填写即可，如 **4 YEARS / 5 YEARS / 6 YEARS**。

### 5. 学历／职业资格 Educational/Professional Qualifications

说明：

1. **⾼中必填**；初中和⼩学经历可以不填。
2. **曾就读的学校／学院／大学／其他教育机构名称**：填写学校**英文**名称。
3. **主修科目**：文科类可填 ARTS；理科类可填 SCIENCES；其他或综合类（不分文理）可填 N/A。
4. **获颁发的学位／资格**：填 HIGH SCHOOL DIPLOMA 等即可。
5. **就读日期**：按实际填写即可，注意格式为 **“月／年”（mm/yy）**。

{% hint style="info" %}
对于 **2026 - 27 入学**的 B29 同学，如高中为**三年**，则一般为**由 09/23 至 06/26**。
{% endhint %}

### 6. 申请人预计在港的生活开支 Applicant's Estimated Cost of Living in Hong Kong

说明：

1. **学费（每学年）**：按 Offer 上的 **Composition Fee** 填写即可。

{% hint style="info" %}
"per annum" 意为 “每年”。

2026 - 27 年度入读之非本地本科生学费：

* **非 STEM 学院：224,000 港币 / 年**
  * 建筑学院、文学院、经管学院、教育学院、法律学院、社会科学学院及未来媒体学院
* **STEM 学院：249,000 港币 / 年**
  * 牙医学院、工程学院、李嘉诚医学院及理学院；生物医学工程学院、计算与数据科学学院（包括与文学院合办开设的 STEM 相关双学位课程）及创新学院
{% endhint %}

2. **住宿（每月）**：
   * **宿舍**：每年 24,000 至 49,000 港元左右；可填写大致数额，**每月 3,000 - 5,000 港元左右**。
   * **租住楼宇**：按自己实际情况填写。
3. **交通费及膳食费（每月约数）、其他（每月）**：一共每月 3,000 - 6,000 港元左右。
4. **总计**：需要换算成每年数额，可填 270,000 - 330,000 港元左右。
5. **简述（如适用）**：一般可以不填。

### 7. 申请人的经济情况 Financial Situation of Applicant

说明：本部分与签证申请系统中 **Financial Support** 一项的选择情况有关。

* 如选择的是 **I will support myself**：
  * **自己名下的存款**数额，填入 “存款” 一栏，并在 “简述” 一栏填入 APPLICANT'S SAVINGS（或留空）；
  * 获得的**奖学金**数额，填入 “入息” 一栏，并在 “简述” 一栏填入 SCHOLARSHIPS（或具体奖学金种类）。
* 如选择的是 **I have a financial sponsor**：
  * **财务担保人（Financial Sponsor，如家长）**&#x540D;下的存款数额，填入 “其他（请简述）” 一栏，并在 “简述” 一栏填入 PARENT'S FINANCIAL SUPPORT / GUARDIAN'S FINANCIAL SUPPORT。
* 如选择的是 **I will support myself and also have a financial sponsor**，可同时填写。

{% hint style="info" %}
1. 根据过往经验，申请人应持有约人民币 100,000 - 150,000 元。
2. 提交的存款证明等材料上显示的数额须**等于或超过**此处所填写的数额。
3. 如仅获得全额**学费**奖学金，仍需提交**额外的财务证明文件**，以支持在香港的**生活开支**。（即便是获得全奖，如果条件允许，最好也可以准备一定数额的存款证明。）
{% endhint %}

### 最后，删去 “不适用者” 并签名

填写完毕后，参考脚标，**将每一页标有 \* 处的不适用者删去**（用横线划去即可，如 ~~删除线~~ ）。

同时，**在适当位置由申请人亲笔签名**。

{% hint style="info" %}
**“签署”、"Signature"** 是指本人签名。对中/英文、简/繁体字、是否连笔、是否能够辨认出姓名等均无要求。

但是，**数字签名和键盘输入不能作为签名**。
{% endhint %}

{% hint style="warning" %}
日期如果使用样表中 “01/01/20xx” 的格式，要注意**香港**常用的是 **“日 / 月 / 年”** 格式。
{% endhint %}

## 三、提醒

1. 检查第 2 页第 1 项的**照片**是否已按要求附上；
2. 检查第 1 页第 1 项、第 3 页第 5 项、每页签名处的**日期格式是否正确**；
3. 如有**曾用名**，检查是否如实填写第 4 页第 9 项 (i) (a)；
4. 检查每页是否已按要求**删去不适用项**、**签名。**
