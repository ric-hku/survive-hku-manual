# CSSAUD 举办的新生系列活动

\*活动详情及报名方式请见 “港大CSSAUD” 公众号。

## 一．Buddy Program

CSSAUD 与学校合作，举办面向新生的 Buddy Program（“挚友计划”）。Buddy Program 将新生们与 B28 及以上的学长姐进行匹配，旨在建立新生们与学长姐之间的最初联系，学长姐将为新生答疑解惑、帮助新生更好适应港大生活。

报名成为 Mentee 后，你将匹配到一至两位相近专业的学长姐作为 Mentor，你可以向 TA 咨询学习生活有关的问题，TA 将协助你做好入学前的各项准备，以帮助你尽快适应香港大学的学习模式和生活。

活动报名时间：七月初

活动报名方式：详情请见 “港大CSSAUD” 公众号

## 二．新生城市见面会

每年七月中至八月初，CSSAUD 将在北京、武汉、杭州、上海、深圳、成都六个城市举办新生城市见面会。届时，香港大学的在读学长学姐将向到场新生及家长介绍香港文化、港大学习与生活资讯，并现场为新生们答疑解惑。

活动不仅能让大家了解行前须知，还能结识同城的新生伙伴，更可领取 CSSAUD 精心定制的新生大礼包，内含干货满满的新生手册与多种精美的入学纪念品。

活动场次信息：

* 7.19 北京场
* 7.21 武汉场
* 7.23 杭州场
* 7.25 & 7.26 上海场
* 7.29 深圳场
* 8.2 成都场

活动报名时间：七月初

活动报名方式：详情请见 “港大CSSAUD” 公众号

## 三．O-Camp

今年八月末，CSSAUD 将开办 O-Camp 迎新营，为初来香港或者已经在香港生活的港大新生提供认识香港、认识港大、结交朋友的机会。通过丰富多样的活动：香港大学 Campus-O 校园内部打卡、夜行太平山、香港西环-O 经典景点打卡、侦探推理 D-game 游戏、烧烤宿营夜等，帮助新生更快融入香港的校园与城市生活，缓解初到陌生环境的不安与孤独感，建立初步的社交圈与归属感。

活动时间：8.25 - 8.28

活动报名时间：八月初

活动报名方式：详情请见 “港大CSSAUD” 公众号

## 四．新生学长姐交流分享会

新生学长姐交流分享会将以线上 Zoom 多会场形式举行。来自不同学院的学长学姐将分别分享专业规划、学习方法与校园资源利用等实用经验。新生可根据自己的专业方向进入相应会场，与高年级学长姐实时提问互动。无论是课程选择、学术发展，还是校园生活适应，都能在此获得第一手指导。活动旨在帮助新生更好地规划大学路径，充分利用港大丰富的学习与成长资源，顺利开启精彩的大学生活。

活动时间：九月中旬

活动报名时间：九月初

活动报名方式：详情请见 “港大CSSAUD” 公众号
