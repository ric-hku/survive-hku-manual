# 签证指南

本指南适用于持有**往来港澳通行证（EEP）**&#x5E76;**从内地直接进入香港**的**内地学生**。

本部分包含：

1. [签证申请详细指南](application.md)
2. [ID995A 表格填写指南](id995a-guide.md)
3. [往来港澳通行证、逗留签注办理指南](exit-entry-permit.md)

## 一、官方网站

官方网站：[内地学生来港就读申请 | HKU Student Visa](https://studentvisa.hku.hk/mainland-student)

核心功能：进入签证申请系统、查看详细流程、下载材料清单、获取官方小贴士等。

{% hint style="info" %}
关于具体如何申请签证的细节，请参考：[签证申请详细指南](application.md)。
{% endhint %}

## 二、时间线

{% stepper %}
{% step %}
### 7 月初

* 收到**录取通知书（Offer Letter）**。
{% endstep %}

{% step %}
### 7 月上旬 – 中旬

* 网上申请：在学校**入学事务部（Admissions Office，AO）**&#x63D0;供的系统中填写信息、缴费、上传材料，以申请签证（入境许可）。
* 上传的电子版文件需要由 **AO 先审核**。\
  **首次上传**的文件需要**最多 5 个工作日**审核；而**再次上传**的文件则会在 **3 个工作日内**审核。
{% endstep %}

{% step %}
### 7 月 – 8 月上、中旬

* AO 审核后，如没有问题，就会将文件提交至**香港入境事务处（Immigration Department，ImmD）**。耐心等待签证（入境许可）即可。
{% endstep %}

{% step %}
### 8 月末以前

* 收到邮件通知，下载电子签证（入境许可）等文件。
* **同时**，向**内地**出入境管理部门办理**逗留签注（D 签）**。

{% hint style="warning" %}
如**没有往来港澳通行证 / 证件已过期 / 有效期不能覆盖整个学习周期**，需**一并申领（换发）往来港澳通行证**。
{% endhint %}
{% endstep %}
{% endstepper %}

## 三、注意事项

1. **尽早开始。**&#x636E;官方信息，**签证申请**通常需要 **6 - 8 周**。此外，**往来港澳通行证和逗留签注**还需要**最多** **7 个工作日**。因此，建议确认录取后立即开始准备材料、申请签证，避免错过新生活动、开学等。
2. 目前，同学们**不用填写、提交 Undertaking Late Submission 表格。**&#x5982;果在填表申请的过程中遇到，可以直接跳过。
3. ID995A 每一页右下角页脚及最后一页整页都有较多要删除的地方，请同学们务必**划横线删除掉文档中所有需删除的内容**（英文对应内容也需一并删去）。同时，打印出来的文件容易缺少填写的内容，请大家务必同时核对打印出的文件**内容是否完整，正确**。
4. 注册签证系统账号选择 Admission Offer 类型时，注意 Firm Offer 及 Conditional Offer 的区别。\
   **通过高考录取的内地学生，获得的基本上是 Firm Offer。**\
   通过国际考试（A-Level、AP、IB 等）录取的同学，请查看自己收到的 Offer 类型。若目前拿到的是 Conditional Offer，在拿到新的 Firm Offer 后也需要在系统中及时重新上传。

## 四、常见问题与解答

### Q1. 我拿到了签证（进入许可），是不是可以直接来香港了？

内地中国居民来港就读，在向香港入境事务处申请到签证（进入许可）之后，还需要向内地出入境管理部门申&#x9886;**《往来港澳通行证》**&#x548C;有关的**赴港签注（逗留签注，D 签）**。

具体细节请参考：[往来港澳通行证、逗留签注办理指南](exit-entry-permit.md)。

### Q2. 我没有办理过往来港澳通行证。可以先申请学生签证吗？

**可以**。表格中相关信息非必填，可先空着。

待申请到学生签证，可以向内地出入境管理部门**同时办理往来港澳通行证和逗留签注**。

### Q3. 我有往来港澳通行证，但马上要过期 / 已经过期了。我还可以用这张通行证申请学生签证吗？

**可以**。虽然换证之后证件号码会发生改变，但学生签证并不会因此失效。

但是，根据内地出入境规定，往来港澳通行证的有效期要比拟申请的签注有效期多 20 天以上。因此，可在申请到学生签证之后，**同时办理换发往来港澳通行证和逗留签注**。

### Q4. 快到开学时间了，但我还没有拿到学生签证 / 往来港澳通行证 / **逗留签注**。怎么办？

一般情况下，学生签证都会在开学前发放。

同时，学校开学前两周为 Add/Drop Period，若因签证延误稍晚抵港，通常不会影响学业；也可联系教授申请线上资源。

此外，如果已取得学生签证，而开学时间临近，**可向出入境管理部门申请加急办理往来港澳通行证、逗留签注**。
