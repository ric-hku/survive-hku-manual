# 圣约翰学院入住指南

### A 基本信息位置&性别&室友 <a href="#a-ji-ben-xin-xi-wei-zhi-xing-bie-shi-you" id="a-ji-ben-xin-xi-wei-zhi-xing-bie-shi-you"></a>

### 1位置 <a href="#id-1-wei-zhi" id="id-1-wei-zhi"></a>

薄扶林道82号（82 Pokfulam Road）；位于赛马会第二学生舍堂村对面。

### 2性别构成 <a href="#id-2-xing-bie-gou-cheng" id="id-2-xing-bie-gou-cheng"></a>

### 4主要建筑 <a href="#id-4-zhu-yao-jian-zhu" id="id-4-zhu-yao-jian-zhu"></a>

马登楼（旧翼，本科生楼，三至八楼），胡文虎楼（新翼，本科生楼，一至二楼，九至十楼），梁基浩楼（食堂与教堂所在），王植庭楼（研究生楼）

### B 居住概况房间&床&家具 <a href="#b-ju-zhu-gai-kuang-fang-jian-chuang-jia-ju" id="b-ju-zhu-gai-kuang-fang-jian-chuang-jia-ju"></a>

### 1房间类型 <a href="#id-1-fang-jian-lei-xing" id="id-1-fang-jian-lei-xing"></a>

本科生单人间，全年房费为HK$32,318（2024-2025），房费分两次缴付，分别位于第一学期初（8月至9约）与第二学期初（1月左右）

强制性餐费 HK$10,900（2023-2024）

Key deposit(HK$$100)和Cautiondeposit(HK$$3,000)在入住时支付，如果学期结束后房间状况良好，押金将全额退还。

### 2房间尺寸 <a href="#id-2-fang-jian-chi-cun" id="id-2-fang-jian-chi-cun"></a>

新翼的房间7至8平米左右，旧翼房间每间10平米（3.1m\*3.1m）。具体房间内部图片可于学院官网（[https://www.stjohns.hk/](https://www.stjohns.hk/) ）内查看注：由于分楼将于Orientation期间决定，所以被分到大房间或小房间也就将会在Orientation期间知晓。

### 3家具 <a href="#id-3-jia-ju" id="id-3-jia-ju"></a>

需自己购买床单、枕头、被子、厚床垫（每间房间默认配有标准薄床垫）。窗帘学院会提供。大件要买的话可以去IKEA质量还可以，运费每件HK$100左右。每年九月份，IKEA都会提供免费送货到宿舍的活动，一般为某个星期的一天。同学们可以提前网上查一下。小件的除了IKEA还可以在西宝城里面的惠康、日本城买。

### 4楼层公共活动室 <a href="#id-4-lou-ceng-gong-gong-huo-dong-shi" id="id-4-lou-ceng-gong-gong-huo-dong-shi"></a>

新翼每个楼层有公共区域，部分有庄友贡献的电视，PS4等等，名义上属楼层财富，楼友可随时使用；旧翼没有公共活动室。

### C 衣物相关洗衣机&衣柜 <a href="#c-yi-wu-xiang-guan-xi-yi-ji-yi-gui" id="c-yi-wu-xiang-guan-xi-yi-ji-yi-gui"></a>

### 1洗衣&烘干 <a href="#id-1-xi-yi-hong-gan" id="id-1-xi-yi-hong-gan"></a>

位置：旧翼5楼走廊尽头有两个洗衣机和两个烘干机，餐厅平地后面（新翼底层）有两个洗衣机和两个烘干机。卫生间有晾衣服的地方（但很小），基本都是靠干衣机。

● 收费：洗衣或烘干一次收费都为10港币，可以使用八达通、微信、或支付宝付费。

● 其他方式：有不少庄友也选择去坚尼地城洗衣店洗，除了花费些许时间上下山送取衣服之外，比较卫生便捷。

### 2衣物储存 <a href="#id-2-yi-wu-chu-cun" id="id-2-yi-wu-chu-cun"></a>

衣柜104c&#x6D;_&#x32;00c&#x6D;_&#x35;0cm（旧翼的衣柜比新翼大…大概大一倍吧哭哭）自己准备衣架，房间里可以自己再买柜子，书柜等等。房间床下有抽屉，门背后也可以挂衣服。

### 2 厨房 (Pantry) <a href="#id-2-chu-fang-pantry" id="id-2-chu-fang-pantry"></a>

有厨房，大部分餐具属于楼层内共用，属于楼层财富。如果有特殊需求也可自备锅碗瓢盆。每周一晚有楼友轮流做宵夜的传统，会用到厨房。厨房里有一个公用的带冷冻的冰箱。有些房间里面有自己的小冰箱（一般是上一届买了留下的），也可以自行购买。西宝城的惠康算是比较近的超市，也可以下到坚尼地城有很多可以买东西的地方，回来不愿意走上坡路可以坐24路小巴

### 3自动售货机 <a href="#id-3-zi-dong-shou-huo-ji" id="id-3-zi-dong-shou-huo-ji"></a>

Hall 内共有 3 台自动贩卖机，分别位于 Common Room 与停车场，贩售各式饮品及零食。

### E 学习环境书桌&自习室 <a href="#e-xue-xi-huan-jing-shu-zhuo-zi-xi-shi" id="e-xue-xi-huan-jing-shu-zhuo-zi-xi-shi"></a>

### 1房间内书桌 <a href="#id-1-fang-jian-nei-shu-zhuo" id="id-1-fang-jian-nei-shu-zhuo"></a>

房间内书桌大概100cm\*60cm吧，有不少房间都会留下一块宜家买来的大板子用来扩大书桌面积（十分推荐！），部分房间有书架和台灯，细节可向楼层阿姨咨询。

### 2图书馆 <a href="#id-2-tu-shu-guan" id="id-2-tu-shu-guan"></a>

圣庄是港大舍堂中为数不多拥有自己的图书馆的舍堂。现在实行门禁制度（有密码），只有现住圣庄本科生与研究生有权限，外人不可带入内。早7点到10点有打扫时间，开放时间无限制。注意final考试时人会比平常多很多。

### 3打印&复印 <a href="#id-3-da-yin-fu-yin" id="id-3-da-yin-fu-yin"></a>

Hall有打印机，实体八达通缴费即可，但是使用不是很方便因为要插U盘，收费跟大学打印机相同。

### F 活动＆相关设施活动室＆活动队 <a href="#f-huo-dong-xiang-guan-she-shi-huo-dong-shi-huo-dong-dui" id="f-huo-dong-xiang-guan-she-shi-huo-dong-shi-huo-dong-dui"></a>

### 1活动室 <a href="#id-1-huo-dong-shi" id="id-1-huo-dong-shi"></a>

a. Junior Common Room：作为 hall 里的文化政治中心，Common Room（CR）见证了太多的历史。2021年CR的修缮完成，除了以往的学生活动空间以外，增加了音乐室，供庄民使用。此外还新添加了学院档案馆，并修缮了学院学生会室。

b. College Bar（酒吧）可以随时在里面打桌球，聊天。偶尔开会或者搞floor的小型聚会也会在里面。

### 2 体育运动 <a href="#id-2-ti-yu-yun-dong" id="id-2-ti-yu-yun-dong"></a>

a. 今年新开了一个gym，位于梁基浩楼的2楼，停车场附近。但是hall内的gym，设施比较少。

b. 离得最近的是二村的孙志新堂，此场馆为室内活动场馆，部分房间需要预约。

c. 其次是位于一村的何添堂，目前只接受group booking。

d. 前往Stanley Ho体育馆有三种方式：1.于学院门口等10路小巴或打的士；2.于学士台（近蒲飞路）打的士；3.通过蒲飞路下山至坚尼地城车站乘坐58路小巴

e. College Office外面有一个平台，打羽毛球/看星星还是足够的。

a. Hall里有一个教堂，供庄民使用。

b. High Table（高桌晚宴）。全hall人员每周一“强制”参加高桌晚宴。如有特殊情况，需要在前一周的周三之前于google forms内提交申请并阐明原因。楼层导师（Tutor）会根据具体情况回复。新生在High table前有一个小酒会（Sherry），是同hall里的教授们，嘉宾及研究生一起吹水。

c. Hall内有许多文化和体育活动，也有不同楼层的活动。这些活动理论上不强制参加，但是hall内非常鼓励参加活动。若同学们不愿意参加活动，可能会影响到下一年的readmission，因此也更应该考虑住别的hall，而非圣约翰堂。一般hall内举办的活动如果有个人原因不能参加只需要给出合理的理由就能够请假。比起参加了多少活动，多少个球队，或是否为圣庄变得更好做出了贡献，圣庄更看重学生的综合能力与在这里所经历的成长。Readmission会注重一个学生的综合能力以及是否适合圣庄的舍堂文化。

d. 新生及旧生都必须要参加Orientation（由学生主办）。如有特殊情况不能参加，可以发邮件与College Office沟通，但估计会失去下一年的入住名额。为考虑参加学生之多元化，Orientation早已改为以英文进行。

### 4 运动队与文化队 <a href="#id-4-yun-dong-dui-yu-wen-hua-dui" id="id-4-yun-dong-dui-yu-wen-hua-dui"></a>

作为港大历史最为悠久的Hall，圣庄拥有众多种类的运动队与文化队并多次摘的红旗。其中运动队包括男子/女子：篮球，足球，排球，棍网球（Lacrosse），曲棍球，壁球，垒球，乒乓球，等等。文化队包括合唱团，舞蹈队，戏剧队，等等。除此以外，也有庄民自发组织的瑜伽课程，舞蹈课程等等，庄民可自行选择，丰富自己的课余生活。

### G Readmission 考核标准 <a href="#greadmission-kao-he-biao-zhun" id="greadmission-kao-he-biao-zhun"></a>

从2016年第一学期开始实行Readmission新政，学生无论年级、背景都要填写申请表，参加面试。面试由 Master，Dean，Associate Dean, Senior Tutor 和 Student Association 代表主持。面试以英文进行，其中根据询问与整理过后我们得到的大致的问题有：对Hall现阶段国际化程度的看法，活动参与度，与舍友同学之间的关系，对Hall的未来建设的意见与建议等。并会借鉴填写的申请表提问，因此每个人被问及的问题会不一样。

Readmission会从每年四月初开始，申请人需要分别通过学院的网站和香港大学Portal网站填写申请。申请于四月末结束，并会在五月初复习周期间统一进行面试。面试结果会于五月末公布。如果申请成功请留意在港大portal确认offer；如果被踢，可选择申请appeal并再次进行面试。Appeal需要两名现住学院学生推荐信，并自己陈述appeal理由。Appeal结果会于6月中公布。

### H 前往圣约翰 <a href="#h-qian-wang-sheng-yue-han" id="h-qian-wang-sheng-yue-han"></a>

### 机场至hall线路 <a href="#ji-chang-zhi-hall-xian-lu" id="ji-chang-zhi-hall-xian-lu"></a>

a. 香港机场打车差不多HK$370-400，建议新生把地址写下来给司机。（地址：薄扶林道82 号，圣约翰学院；St.John’s College, 82 Pokfulam Road, Hong Kong）

b. 香港地铁机场快线到港大站HK100左右，行李不多可从香港大学C1口出，步行至学院。行李多建议乘的士吧。如果打车建议从A出口乘电梯到薄扶林道，那个方向打车顺路不用过马路(起步价HK24+每件行李HK$6)。另外一个选择是A出口上到薄扶林道地面有一个巴士站“香港大学西闸”，乘坐任何一辆到蒲飞路巴士站的巴士都可以。到蒲飞路下车后是个加油站，沿着你下车那条行道的车流方向走一段上坡路，过一个红绿灯，再走150-200米就可以看到正门（对面就是Flora Ho体育馆很明显）。如果找不到可以问薄扶林道82号怎么走，正门前面有非常明显的“82”号字。

c. 香港机场乘坐大巴 A10/A11/A12（HK$45）于西区海底隧道下车，免费换乘 970/970X至蒲飞路下车。时间为70～80分钟。

注: College Office（学院办公室）位于胡文虎楼一楼，可于梁基浩楼乘坐电梯至4楼，然后便可看到顶层平台上的学院办公室。College Office 工作日工作时间至5：30pm，新入住的同学尽量在学院办公室开门的时候来；不然可以提前与College Office联系，会有工作人员帮忙把你的钥匙放于马登楼（新翼）Counter处（马登楼Counter 24小时工作）。
