# GPA 与荣誉学位等级

## 一、Letter Grades 与 GPA

### 1. Letter Grades 字母等级

字母等级（Letter Grades）会按如下方式转换为积点（Grade Point）：

| Grade 等级                | Standard 标准     | Grade Point 积点           |
| ----------------------- | --------------- | ------------------------ |
| <p>A+</p><p>A<br>A-</p> | 优秀 Excellent    | <p>4.3<br>4.0<br>3.7</p> |
| <p>B+<br>B<br>B-</p>    | 良好 Good         | <p>3.3<br>3.0<br>2.7</p> |
| <p>C+<br>C<br>C-</p>    | 满意 Satisfactory | <p>2.3<br>2.0<br>1.7</p> |
| <p>D+<br>D</p>          | 合格 Pass         | <p>1.3<br>1.0</p>        |
| F                       | 不合格 Fail        | 0                        |

{% hint style="info" %}
不适用于 BDS、MBBS 学生。
{% endhint %}

### 2. GPA

GPA（Grade Point Average，平均积点）就是各个课程所获积点（Grade Point）的平均值。

不合格的成绩也会被计入 GPA。

不同的 GPA 有：

* SGPA（Semester GPA，学期平均积点），某个学期的 GPA；
* YGPA（Year GPA，学年平均积点），某个学年的 GPA；
* CGPA（Cumulative GPA，总平均积点），从入学到某个时刻累计的 GPA；
* GGPA（Graduation GPA，毕业平均积点），从入学到毕业累计的 GPA。

{% hint style="info" %}
对于 2017 – 18 学年及以后入学的学生，Common Core 课程在计入 GGPA 时有特殊规则。

详见：[六、GGPA 计算特别规定 | Common Core 指南](https://ric-hku.gitbook.io/survive-hku-manual/freshman-guide/course-selection/ug5-requirements/common-core#liu-ggpa-ji-suan-te-bie-gui-ding)。
{% endhint %}

### 3. Pass/Fail 合格 / 不合格式评分

此外，有的课程不采用字母等级（Letter Grades），而是采用以下评分方式：

* 合格 Pass（P）
* 不合格 Fail（F）
* 优异 Distinction（DI）

采用这种方式的课程，成绩不会被计入 GPA。

{% hint style="info" %}
类似地，通过从其他院校转学分（Credit Transfer）、Advanced Standing 获得的学分，也不会计入 GPA。
{% endhint %}

## 二、荣誉学位等级 Honours Classifications

荣誉学位的评定基于学生毕业时的 GGPA：

| 荣誉学位等级 Class of Honours                                                            | GGPA 范围                                            |
| ---------------------------------------------------------------------------------- | -------------------------------------------------- |
| First Class Honours 一级荣誉学位                                                         | 3.60 – 4.30                                        |
| <p>Second Class Honours 二级荣誉学位<br>Division One 二级荣誉甲等<br>Division Two 二级荣誉乙等</p> | <p>（2.40 – 3.59）<br>3.00 – 3.59<br>2.40 – 2.99</p> |
| Third Class Honours 三级荣誉学位                                                         | 1.70 – 2.39                                        |
| Pass 普通学位                                                                          | 1.00 – 1.69                                        |

{% hint style="info" %}
不适用于 BChinMed、BDS、MBBS 学生。
{% endhint %}

不过，如要获得荣誉学位，通常 50% 的学分必须为字母等级（Letter Grades）。否则，一般只能获得普通学位。

{% hint style="info" %}
主考委员会（Boards of Examiners）可根据其绝对裁量权，并在有正当理由时，给一个被认为学术表现优异，但 GGPA 略低于上表标准（如 0.1）的学生授予较高等级的荣誉学位。

如有疑问，请向所属学院咨询。
{% endhint %}

## 三、学业成绩表（Transcript）上可能出现的其他符号

* EX：Exemption granted 已批准豁免申请
* FL：Not examined – counted as Fail  &#x20;未参加考试（计为不合格）
* N：Absence from examination due to illness 因病缺席考试
* NC：Did not complete 未完成
* NE：Not examined – NOT counted as Fail 未参加考试（不计为不合格）
* NS：Non-satisfactory completion 未达标
* NV：No evaluation – course continues in the following semester/year 暂不评定（课程延续至下一学期/学年）
* PE：Results not yet available 成绩尚未公布
* SC：Satisfactory completion 达标
* SE：Continuous assessment, result incorporated in summative assessment/examination 持续性评估，成绩计入总结性评估/考试
* WD：Withdrew from course/module 退课/退选模块

## 四、辍学 Discontinuation of Studies

根据规定，如果出现如下情况，则将会被要求辍学：

* 在连续的两个学期（不含夏季学期）中，合计未能修满 36 学分（除非不需要）；或者
* 连续两个学期的 SGPA（Semester GPA，学期 GPA）低于 1.0；或者
* 超过了最长修读期限（例如，需修读 4 年的学位，最长一般不得超过 6 年）。

如发生以上情况，学院学生表现及辍学审核委员会（Faculty Review Committee on Student Performance and Discontinuation, FRC）会先与学生进行面谈，了解学生可能遇到的困难并提供建议。如有必要，FRC 会将案例移交学校的辍学委员会（Committee on Discontinuation, COD）审议。

## 五、常见问题与解答

### Q1. 我的家长 / 监护人能否获知我的成绩？

香港大学所有学生均受香港《个人资料（私隐）条例》保护。因此，学生家长 / 监护人**并无获取学生的个人资料（如学业成绩）的必然权利**。一般情况下，大学会直接与学生通信联系，而非其家长 / 监护人。

然而，鉴于国际及内地全日制本科生需离开原居地及家人来大学学习，当他们因未达大学 / 课程规定的最低成绩要求由学院转介辍学委员会就应否终止其学习作最终决定时 ，其家长 / 监护人或希望知悉有关情况。

为此，有关学生须填写个人资料披露同意书（中文或英文版），表明是否同意大学在上述情况下，向其家长 / 监护人 / 近亲披露相关资料。

详情请参阅学务及考试部（Academic Support and Examinations Section）在开学前后向学生发送的题为 “Consent Form for Disclosure of Personal Information of Full-time International and Mainland China Undergraduate Students”（国际及内地全日制本科生个人资料披露同意书）的邮件。
